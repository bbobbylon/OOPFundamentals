Graphs — Coding Practice

Six classic interview problems — grid BFS/DFS, cycle detection, Union-Find, and 2-coloring. Real code, real hidden tests.

No special node structures here — graphs in these exercises are just plain data: a 2D grid of numbers, a flat list of [a, b] edge pairs, or an adjacency list (an array where graph[i] is the array of neighbors for node i). The skill being tested is choosing the right traversal (DFS for "explore a connected region," BFS for "shortest distance / spreads outward level by level," Union-Find for "are these two things connected") and avoiding infinite loops by tracking visited state. Pick a language tab (JavaScript, TypeScript, or Python — all three run for real in your browser), write the function, press Run Tests. Stuck? Use a hint, or jump to the Graphs visualizer for the underlying technique.
