What is a graph — and how do BFS, DFS, Dijkstra, and topological sort each solve a different class of problems?

A graph is the most general data structure: a set of nodes (vertices) connected by edges. Unlike trees (which are special graphs — connected, acyclic, with exactly one root), graphs can have cycles, multiple paths between nodes, disconnected components, and edges with weights and directions. Graphs model the real world naturally: social networks (nodes = users, edges = friendships), maps (nodes = cities, edges = roads with distances), dependency systems (nodes = packages, edges = "requires"), and microservice architectures (nodes = services, edges = calls). Directed vs undirected: undirected edges go both ways (friendship = bidirectional). Directed edges (arcs) have a single direction (A calls B doesn't mean B calls A). Representations: Adjacency Matrix (2D array, O(1) edge lookup, O(V²) space — good for dense graphs), Adjacency List (Map<Node, List<Edge>>, O(degree) edge lookup, O(V+E) space — good for sparse graphs). Most real-world graphs are sparse. BFS (Breadth-First Search): explore neighbors before going deeper. Uses a queue. Property: finds the SHORTEST PATH in unweighted graphs (fewest edges). Time: O(V+E). DFS (Depth-First Search): go as deep as possible, then backtrack. Uses a stack (or recursion). Good for: cycle detection, connected components, topological sort, maze solving. Topological sort: linear ordering of directed graph nodes such that every edge u→v has u before v. Only possible on DAGs (Directed Acyclic Graphs — no cycles). Algorithm: DFS, add each node to front when fully processed. Use cases: task scheduling with dependencies, package install order, build systems (Maven module build order). Dijkstra's algorithm: shortest path in a weighted graph with non-negative edge weights. Uses a min-heap (priority queue). For each extracted minimum-distance node, relax its neighbors. O((V + E) log V). Not applicable to negative weights (use Bellman-Ford).

BFS shortest path

// BFS: find shortest path (fewest edges) // from source to target in unweighted graph int bfs(Map<Integer,List<Integer>> graph, int src, int target) { Set<Integer> visited = new HashSet<>(); Queue<int[]> queue = new LinkedList<>(); queue.offer(new int[]{src, 0}); // [node, distance] visited.add(src); while (!queue.isEmpty()) { int[] curr = queue.poll(); int node = curr[0], dist = curr[1]; if (node == target) return dist; for (int neighbor : graph.getOrDefault(node, List.of())) { if (!visited.contains(neighbor)) { visited.add(neighbor); queue.offer(new int[]{neighbor, dist+1}); } } } return -1; // not reachable } // BFS explores level by level (all nodes at dist d // before any at dist d+1) → first time we reach // target MUST be the shortest path

Topological sort (Kahn's)

// Topological sort via Kahn's algorithm (BFS-based): // Input: DAG of dependencies // Output: order to process nodes with no dependency first List<Integer> topoSort(int n, int[][] edges) { int[] inDegree = new int[n]; List<List<Integer>> adj = ...; // build adj list for (int[] e : edges) { inDegree[e[1]]++; // e[0] → e[1]: e[1] has a dep } Queue<Integer> q = new LinkedList<>(); for (int i = 0; i < n; i++) if (inDegree[i] == 0) q.offer(i); // no deps List<Integer> order = new ArrayList<>(); while (!q.isEmpty()) { int node = q.poll(); order.add(node); for (int next : adj.get(node)) { if (--inDegree[next] == 0) q.offer(next); } } return order.size() == n ? order : null; // null = cycle! } // Detects cycles: if result has <n nodes, cycle exists

Dijkstra shortest path

// Dijkstra: shortest weighted path (no negative edges) // Uses min-heap for O((V+E) log V) int[] dijkstra(int[][] graph, int src) { int n = graph.length; int[] dist = new int[n]; Arrays.fill(dist, Integer.MAX_VALUE); dist[src] = 0; // min-heap: [distance, node] PriorityQueue<int[]> pq = new PriorityQueue<>((a,b) -> a[0]-b[0]); pq.offer(new int[]{0, src}); while (!pq.isEmpty()) { int[] curr = pq.poll(); int d = curr[0], u = curr[1]; if (d > dist[u]) continue; // stale entry for (int v = 0; v < n; v++) { if (graph[u][v] > 0) { int newDist = dist[u] + graph[u][v]; if (newDist < dist[v]) { dist[v] = newDist; pq.offer(new int[]{newDist, v}); } } } } return dist; // dist[i] = min distance from src to i }

In CIAM / Context: Graphs appear in CIAM in role/permission hierarchies (directed graph: ADMIN → USER → READ_ONLY), microservice dependency graphs (which service depends on which — topological sort determines startup order), and OAuth flow analysis (which redirect URIs are reachable from which clients). Maven's multi-module reactor build order is computed by topological sort on the dependency DAG between modules. Spring's bean dependency resolution is also a topological sort.

Graph Fundamentals

A graph G = (V, E) consists of vertices (nodes) V and edges E connecting pairs of vertices. Graphs model networks: roads, social connections, dependencies, state machines, the internet.

Graph Types

Undirected: edges have no direction (A—B means you can go A→B or B→A). Social friendships, roads.
Directed (Digraph): edges have direction (A→B ≠ B→A). Web links, dependencies, Twitter follows.
Weighted: each edge has a numeric weight/cost. Roads with distances, network with latency.
DAG: Directed, no cycles. Build systems (Make, Gradle), spreadsheet formulas, git history.
Dense graph: E ≈ V². Favor adjacency matrix. Sparse graph: E ≪ V². Favor adjacency list.

Graph Representation

How you store a graph fundamentally affects algorithm speed. Two main options: adjacency matrix (2D array) and adjacency list (array of lists).

Adjacency Matrix

// matrix[i][j] = edge weight (0 = no edge) // Example: 4-node directed weighted graph int[][] matrix = { // A B C D /* A */ {0, 4, 0, 8}, /* B */ {0, 0, 3, 0}, /* C */ {0, 0, 0, 2}, /* D */ {0, 0, 0, 0} }; // Edge A→B weight 4, A→D weight 8, B→C weight 3, C→D weight 2 // Check edge existence: O(1) matrix[0][1] != 0 // A→B exists? // Get all neighbors of A: O(V) — scan row 0 for (int j = 0; j < n; j++) if (matrix[0][j] != 0) process(j);
Space: O(V²) always — even for sparse graphs. 1000 nodes = 1M cells. Bad for sparse.

Adjacency List

// Map each vertex to its neighbor list Map<String, List<int[]>> graph = new HashMap<>(); // int[] = {neighbor, weight} graph.put("A", List.of(new int[]{1,4}, new int[]{3,8})); graph.put("B", List.of(new int[]{2,3})); graph.put("C", List.of(new int[]{3,2})); graph.put("D", List.of()); // Iterate neighbors of A: O(degree(A)) for (int[] edge : graph.get("A")) { int neighbor = edge[0], weight = edge[1]; } // Java simple int[][] adjacency list: List<int[]>[] adj = new List[n]; Arrays.fill(adj, new ArrayList<>()); adj[u].add(new int[]{v, w}); // add edge u→v weight w
Space: O(V + E) — only stores actual edges. Preferred for sparse graphs (most real-world graphs).

Breadth-First Search (BFS)

Explore all neighbors at distance 1, then distance 2, etc. Uses a Queue. Finds the shortest path in unweighted graphs. Also used for: level order, connected components, bipartite check.

void bfs(List<Integer>[] adj, int start, int n) { int[] dist = new int[n]; Arrays.fill(dist, -1); dist[start] = 0; Queue<Integer> q = new ArrayDeque<>(); q.add(start); while (!q.isEmpty()) { int u = q.poll(); System.out.println("Visit: " + u + " dist=" + dist[u]); for (int v : adj[u]) { if (dist[v] == -1) { // not visited dist[v] = dist[u] + 1; q.add(v); } } } // dist[v] = shortest hop count from start to v }
BFS finds shortest paths in unweighted graphs because it processes nodes in order of their distance from the source. First time you reach a node = shortest path.

BFS Use Cases

  • Shortest path in unweighted graph
  • Social network "degrees of separation"
  • Web crawlers (breadth-first crawl)
  • Maze solving (minimum moves)
  • Bipartite graph check (2-coloring)
  • Garbage collection (mark-and-sweep)
  • Level-order traversal of any graph/tree

Depth-First Search (DFS)

Go as deep as possible before backtracking. Uses a Stack (recursion or explicit). Finds connected components, detects cycles, drives topological sort.

// Recursive DFS boolean[] visited = new boolean[n]; void dfs(List<Integer>[] adj, int u) { visited[u] = true; System.out.println("Enter: " + u); for (int v : adj[u]) { if (!visited[v]) dfs(adj, v); } System.out.println("Exit: " + u); } // Cycle detection (directed graph): // 3 states: WHITE(0)=unvisited, GRAY(1)=in-stack, BLACK(2)=done int[] color = new int[n]; boolean hasCycle = false; void dfsCycle(int u) { color[u] = 1; // GRAY: on current path for (int v : adj[u]) { if (color[v] == 1) hasCycle = true; // back edge! else if (color[v] == 0) dfsCycle(v); } color[u] = 2; // BLACK: fully processed }

DFS Edge Types (Directed Graph)

Tree edge: Edge explored for first time. Builds the DFS tree.
Back edge: Points to an ancestor in DFS tree. Indicates a cycle!
Forward edge: Points to a descendant (already visited). Only in directed.
Cross edge: Points to a node in different DFS subtree.

Connected Components

int components = 0; for (int i = 0; i < n; i++) { if (!visited[i]) { dfs(adj, i); components++; } } // components = count of connected groups

Topological Sort

Order vertices of a DAG so that every edge (u → v) has u appearing before v. Used for: build order, course prerequisites, package dependency resolution, spreadsheet evaluation.

Only valid on DAGs (Directed Acyclic Graphs). A topological sort doesn't exist if there is a cycle (circular dependency). If you detect a cycle during topological sort, the graph has no valid ordering.

Algorithm 1: Kahn's (BFS-based, in-degree)

// Kahn's algorithm: process 0-in-degree nodes first List<Integer> topoSort(List<Integer>[] adj, int n) { int[] inDegree = new int[n]; for (int u = 0; u < n; u++) for (int v : adj[u]) inDegree[v]++; Queue<Integer> q = new ArrayDeque<>(); for (int i = 0; i < n; i++) if (inDegree[i] == 0) q.add(i); // no prerequisites List<Integer> order = new ArrayList<>(); while (!q.isEmpty()) { int u = q.poll(); order.add(u); for (int v : adj[u]) { if (--inDegree[v] == 0) q.add(v); // dependency satisfied } } // If order.size() != n → graph has a cycle! return order.size() == n ? order : Collections.emptyList(); }

Step-by-Step Example

// Courses: A→C, B→C, C→D (A,B before C, C before D)
inDegree: A=0, B=0, C=2, D=1

Queue: [A, B] → process A
→ decrement inDegree[C]=1. Queue: [B]
process B → inDegree[C]=0 → enqueue C
Queue: [C]
process C → inDegree[D]=0 → enqueue D
Queue: [D]
process D. Done.

Order: A, B, C, D ✓
// A, B, C, D is valid; so is B, A, C, D

Algorithm 2: DFS Post-Order

void dfsPostOrder(List<Integer>[] adj, int u, boolean[] visited, Deque<Integer> stack) { visited[u] = true; for (int v : adj[u]) if (!visited[v]) dfsPostOrder(adj, v, visited, stack); stack.push(u); // push AFTER all descendants } List<Integer> topoSortDFS(List<Integer>[] adj, int n) { boolean[] visited = new boolean[n]; Deque<Integer> stack = new ArrayDeque<>(); for (int i = 0; i < n; i++) if (!visited[i]) dfsPostOrder(adj, i, visited, stack); List<Integer> result = new ArrayList<>(stack); return result; // stack top = first in topological order }
Post-order DFS: A node is added to the stack only after ALL its descendants have been processed. When you pop the stack, you get topological order (reverse of post-order).

Real-World Uses

  • Gradle/Maven — build modules in dependency order
  • npm/pip — install packages in dependency order
  • Spreadsheets — evaluate cells that depend on others
  • LeetCode 207 — "Course Schedule" (cycle detection)
  • LeetCode 210 — "Course Schedule II" (actual order)

Dijkstra's Algorithm

Finds shortest paths from a source to all other vertices. Requires non-negative edge weights. Uses a min-heap (priority queue) to always process the nearest unvisited vertex.

Dijkstra fails with negative weights! Once a node is finalized, its distance is considered optimal. A negative edge could offer a shorter path to an already-finalized node. Use Bellman-Ford for negative weights.
// Dijkstra's with PriorityQueue — O((V+E) log V) int[] dijkstra(List<int[]>[] adj, int src, int n) { int[] dist = new int[n]; Arrays.fill(dist, Integer.MAX_VALUE); dist[src] = 0; // PriorityQueue: [cost, vertex] PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]); pq.offer(new int[]{0, src}); while (!pq.isEmpty()) { int[] curr = pq.poll(); int cost = curr[0], u = curr[1]; if (cost > dist[u]) continue; // stale entry, skip for (int[] edge : adj[u]) { int v = edge[0], w = edge[1]; if (dist[u] + w < dist[v]) { dist[v] = dist[u] + w; pq.offer(new int[]{dist[v], v}); // may add duplicate } } } return dist; // dist[v] = shortest distance from src to v }

Bellman-Ford Algorithm

Handles negative weights. Relaxes all edges V-1 times. A Vth relaxation that still improves = negative cycle detected.

int[] bellmanFord(int[][] edges, int src, int n) { // edges[i] = {u, v, weight} int[] dist = new int[n]; Arrays.fill(dist, Integer.MAX_VALUE); dist[src] = 0; // Relax all edges V-1 times for (int i = 0; i < n - 1; i++) { for (int[] edge : edges) { int u = edge[0], v = edge[1], w = edge[2]; if (dist[u] != Integer.MAX_VALUE && dist[u] + w < dist[v]) dist[v] = dist[u] + w; } } // Vth pass: if still relaxing → negative cycle for (int[] edge : edges) { int u = edge[0], v = edge[1], w = edge[2]; if (dist[u] + w < dist[v]) throw new RuntimeException("Negative cycle!"); } return dist; }

Why V-1 Iterations?

The shortest path between any two vertices visits at most V-1 edges (otherwise it would revisit a vertex → a cycle → could be shortened). After V-1 relaxations, all shortest paths are found.

Floyd-Warshall — All-Pairs Shortest Path

// O(V³) time, O(V²) space // Works with negative weights (not negative cycles) int[][] floydWarshall(int[][] dist) { int n = dist.length; // dist[i][j] = direct weight, INF if no edge, 0 if i==j // Try each vertex k as intermediate for (int k = 0; k < n; k++) for (int i = 0; i < n; i++) for (int j = 0; j < n; j++) if (dist[i][k] + dist[k][j] < dist[i][j]) dist[i][j] = dist[i][k] + dist[k][j]; // Check for negative cycles: for (int i = 0; i < n; i++) if (dist[i][i] < 0) throw new RuntimeException("Neg cycle"); return dist; // dist[i][j] = shortest i→j }
Floyd-Warshall insight: For each pair (i,j), consider whether routing through vertex k makes it shorter. The DP recurrence: dist(i,j,k) = min(dist(i,j,k-1), dist(i,k,k-1) + dist(k,j,k-1)).

When to Use

  • Small dense graph (V ≤ 500 or so)
  • Need all-pairs, not just one source
  • Example: network routing tables
  • Example: "transitive closure" of a graph
O(V³) makes it impractical for V > 1000. Run Dijkstra V times for large sparse graphs instead.

Minimum Spanning Tree (MST)

A spanning tree connecting all V vertices with minimum total edge weight, using exactly V-1 edges and no cycles. Assumes undirected, connected, weighted graph.

Applications: Network design (minimum cable to connect all cities), cluster analysis, approximation algorithms for TSP, road/pipeline planning.

Kruskal's Algorithm — Edge-Greedy

// Sort all edges by weight, add if no cycle (Union-Find) int[] parent, rank; int find(int x) { if (parent[x] != x) parent[x] = find(parent[x]); // path compress return parent[x]; } boolean union(int a, int b) { int ra = find(a), rb = find(b); if (ra == rb) return false; // same component → cycle! if (rank[ra] < rank[rb]) parent[ra] = rb; else if (rank[ra] > rank[rb]) parent[rb] = ra; else { parent[rb] = ra; rank[ra]++; } return true; } List<int[]> kruskal(int[][] edges, int n) { // edges[i] = {weight, u, v} Arrays.sort(edges, (a,b) -> a[0] - b[0]); // sort by weight parent = new int[n]; rank = new int[n]; for (int i = 0; i < n; i++) parent[i] = i; List<int[]> mst = new ArrayList<>(); for (int[] e : edges) { if (union(e[1], e[2])) { // no cycle mst.add(e); if (mst.size() == n - 1) break; // V-1 edges: done } } return mst; }

Kruskal Step-by-Step

// Edges sorted: (1,A-B),(2,C-D),(3,B-C),(4,A-D),(5,B-D)
Add (1,A-B): A and B now connected ✓
Add (2,C-D): C and D now connected ✓
Add (3,B-C): connects {A,B} ∪ {C,D} ✓
Skip (4,A-D): A and D already same component ✗
MST complete (V-1=3 edges added)

MST total weight: 1+2+3 = 6

Prim's Algorithm — Vertex-Greedy

// Grow MST from a seed vertex, always add cheapest edge // that connects a new vertex. O((V+E) log V) int prim(List<int[]>[] adj, int n) { boolean[] inMST = new boolean[n]; int[] minCost = new int[n]; Arrays.fill(minCost, Integer.MAX_VALUE); minCost[0] = 0; // PQ: [cost, vertex] PriorityQueue<int[]> pq = new PriorityQueue<>((a,b) -> a[0]-b[0]); pq.offer(new int[]{0, 0}); // start from vertex 0 int totalCost = 0; while (!pq.isEmpty()) { int[] curr = pq.poll(); int cost = curr[0], u = curr[1]; if (inMST[u]) continue; inMST[u] = true; totalCost += cost; for (int[] edge : adj[u]) { int v = edge[0], w = edge[1]; if (!inMST[v] && w < minCost[v]) { minCost[v] = w; pq.offer(new int[]{w, v}); } } } return totalCost; // minimum spanning tree weight }
