Trees & BST

Traversals, DFS patterns, BFS level-order, path problems, and BST-specific techniques.

🧩 What are tree interview patterns — and how do DFS, BFS, path problems, and BST constraints each require a different template?

Tree problems are a staple of every interview because they test recursive thinking, which is one of the clearest signals of strong CS foundations. Nearly all tree problems can be solved with 4 templates. Template 1 — DFS Traversals: In-order (left → root → right) produces sorted output on a BST. Pre-order (root → left → right) is used to serialize a tree. Post-order (left → right → root) is used when you need to process children before parents (calculate subtree properties, evaluate an expression tree). Every DFS traversal is the same recursive skeleton: base case (if null, return or return 0), recurse left, recurse right, combine. Template 2 — BFS Level-Order: uses a Queue. Dequeue all nodes at the current level, enqueue their children. Uses: Binary Tree Level Order Traversal, Minimum Depth of Binary Tree, Connect Level Order Siblings, Right Side View (last node of each level). Level-order is the go-to when the answer is about "levels," "depth," or "nearest node." Template 3 — Path Problems (DFS with return value): carry a "running sum" or "running path" down during recursion, return the best value from left/right subtree, and combine. Problems: Path Sum I (does any root-to-leaf path sum to target?), Path Sum II (return all such paths), Maximum Path Sum (path can go up-and-over through root — the tricky variant), Diameter of Binary Tree (max left depth + max right depth at each node). Key insight: the DFS return value and the "global best" answer are often different — the return value propagates only ONE side (left OR right) to maintain a valid path, while the answer at each node considers BOTH sides. Template 4 — BST-specific: exploit the BST invariant (left < root < right) to achieve O(h) searches instead of O(n). BST problems: Validate BST (pass min/max bounds down during recursion), Search in BST, Lowest Common Ancestor of BST (if both nodes < root, go left; both > root, go right; else root is LCA), Kth Smallest Element in BST (in-order traversal count), Serialize/Deserialize BST (preorder + BST bounds to reconstruct without separator). BST vs Binary Tree: if the problem says "BST" or "sorted," the BST invariant is a property you should exploit. If it just says "binary tree," you likely need a full O(n) traversal.

DFS — the universal template

// Universal DFS tree template // Replace "..." with what you want to compute // Returns a value that propagates up to parent int dfs(TreeNode node) { // Base case: null node if (node == null) return 0; // (or null, or false, or INT_MIN) // Recurse into children: int leftVal = dfs(node.left); // solve left subtree int rightVal = dfs(node.right); // solve right subtree // Combine results to return to parent: return Math.max(leftVal, rightVal) + 1; // example: max depth } // Max Depth specialization: int maxDepth(TreeNode root) { if (root == null) return 0; return Math.max(maxDepth(root.left), maxDepth(root.right)) + 1; } // Diameter specialization: (use global variable for answer) int diameter = 0; int dfsHeight(TreeNode n) { if (n==null) return 0; int L=dfsHeight(n.left), R=dfsHeight(n.right); diameter = Math.max(diameter, L+R); // best path THROUGH this node return Math.max(L,R)+1; // propagate ONLY one side to parent }

BFS Level-Order traversal

// Binary Tree Level Order Traversal // Returns List<List<Integer>> — each inner list = one level // Template: queue-based, dequeue whole level at a time List<List<Integer>> levelOrder(TreeNode root) { List<List<Integer>> result = new ArrayList<>(); if (root == null) return result; Queue<TreeNode> q = new LinkedList<>(); q.offer(root); // seed the queue while (!q.isEmpty()) { int levelSize = q.size(); // ALL nodes currently in q = this level List<Integer> level = new ArrayList<>(); for (int i=0; i<levelSize; i++) { TreeNode node = q.poll(); level.add(node.val); if (node.left != null) q.offer(node.left); if (node.right != null) q.offer(node.right); } result.add(level); } return result; // O(n) time and space } // Right Side View: just take last element of each level // Zigzag: alternate adding to front vs back with a Deque

BST — Validate + LCA

// Validate BST: pass bounds down recursion // At each node: value must be in (min, max) range // Naive "left.val < root.val" check fails for deeper violations boolean isValidBST(TreeNode root) { return validate(root, Long.MIN_VALUE, Long.MAX_VALUE); } boolean validate(TreeNode node, long min, long max) { if (node==null) return true; // null leaf is valid if (node.val<=min||node.val>=max) return false; // out of bounds! return validate(node.left, min, node.val) // left: max = current && validate(node.right, node.val, max); // right: min = current } // NOTE: Long bounds needed to handle Integer.MIN/MAX_VALUE edge case // LCA of BST — exploit BST ordering: TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) { if (p.val<root.val && q.val<root.val) // both in left subtree return lowestCommonAncestor(root.left, p, q); if (p.val>root.val && q.val>root.val) // both in right subtree return lowestCommonAncestor(root.right, p, q); return root; // p and q are on different sides → root IS the LCA } // O(h) — no need to search whole tree

Interview / Context: Tree problems are the most reliable way interviewers test recursion. The single most important skill: being able to say "my DFS returns X, and the global answer is updated with Y at each node — these are two different things." This separation is what makes Maximum Path Sum and Diameter solvable without bugs. In your CIAM work: Spring's ApplicationContext is a tree of bean definitions with child contexts (OAuth2 security context is a child of the parent context). Ping IDM policy trees and journey node trees are literal trees traversed depth-first during authentication. JWT scope hierarchies (admin > write > read) are modeled as trees in some authorization frameworks.

Iterative Inorder (DFS with Stack)
public List<Integer> inorderTraversal(TreeNode root) { List<Integer> result = new ArrayList<>(); Deque<TreeNode> stack = new ArrayDeque<>(); TreeNode curr = root; while (curr != null || !stack.isEmpty()) { while (curr != null) { stack.push(curr); curr = curr.left; } // go left curr = stack.pop(); result.add(curr.val); // visit curr = curr.right; // go right } return result; }
BFS Level-Order
public List<List<Integer>> levelOrder(TreeNode root) { List<List<Integer>> result = new ArrayList<>(); if (root == null) return result; Queue<TreeNode> q = new LinkedList<>(); q.add(root); while (!q.isEmpty()) { int size = q.size(); List<Integer> level = new ArrayList<>(); for (int i = 0; i < size; i++) { TreeNode node = q.poll(); level.add(node.val); if (node.left != null) q.add(node.left); if (node.right != null) q.add(node.right); } result.add(level); } return result; }
PATTERN 1

DFS Recursive Template

Time: O(n) Space: O(h) — height of tree Most tree problems: depth, subtree properties, comparisons
The universal DFS template: base case (null → return default), recurse left, recurse right, combine. The magic is that the recursion stack handles backtracking for you. Think: "What do I need from my children?" then combine with current node's value.

DFS Template — Max Depth
// Template: base, recurse left/right, combine public int maxDepth(TreeNode root) { if (root == null) return 0; // base case int leftDepth = maxDepth(root.left); // recurse left int rightDepth = maxDepth(root.right); // recurse right return 1 + Math.max(leftDepth, rightDepth); // combine }
Same Tree
public boolean isSameTree(TreeNode p, TreeNode q) { if (p == null && q == null) return true; if (p == null || q == null) return false; if (p.val != q.val) return false; return isSameTree(p.left, q.left) && isSameTree(p.right, q.right); }
Diameter of Binary Tree
int maxDiameter = 0; public int diameterOfBinaryTree(TreeNode root) { height(root); return maxDiameter; } private int height(TreeNode node) { if (node == null) return 0; int l = height(node.left), r = height(node.right); maxDiameter = Math.max(maxDiameter, l + r); // path through node return 1 + Math.max(l, r); }
Classic Problems
  • Maximum Depth of Binary Tree — return 1 + max(left, right)
  • Same Tree — compare structure and values recursively
  • Symmetric Tree — compare mirror(left.left, right.right) and mirror(left.right, right.left)
  • Balanced Binary Tree — return -1 from height if unbalanced, propagate up
  • Diameter of Binary Tree — track global max of left height + right height
PATTERN 2

Path Problems & LCA

Time: O(n) Space: O(h) Root-to-leaf paths, max path sum, lowest common ancestor
Binary Tree Maximum Path Sum
int maxSum = Integer.MIN_VALUE; public int maxPathSum(TreeNode root) { dfs(root); return maxSum; } private int dfs(TreeNode node) { if (node == null) return 0; int left = Math.max(0, dfs(node.left)); // discard negative paths int right = Math.max(0, dfs(node.right)); maxSum = Math.max(maxSum, node.val + left + right); // path through node return node.val + Math.max(left, right); // best single path upward }
Lowest Common Ancestor (LCA)
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) { if (root == null || root == p || root == q) return root; TreeNode left = lowestCommonAncestor(root.left, p, q); TreeNode right = lowestCommonAncestor(root.right, p, q); // if both sides returned non-null, current node is the LCA if (left != null && right != null) return root; return (left != null) ? left : right; }
Path Sum II (root-to-leaf paths summing to target)
public List<List<Integer>> pathSum(TreeNode root, int target) { List<List<Integer>> result = new ArrayList<>(); dfs(root, target, new ArrayList<>(), result); return result; } private void dfs(TreeNode node, int remain, List<Integer> path, List<List<Integer>> res) { if (node == null) return; path.add(node.val); if (node.left == null && node.right == null && remain == node.val) res.add(new ArrayList<>(path)); // found a valid path dfs(node.left, remain - node.val, path, res); dfs(node.right, remain - node.val, path, res); path.remove(path.size() - 1); // backtrack }
BST

BST-Specific Problems

BST property: for every node, all left descendants < node.val < all right descendants. This allows O(log n) search in a balanced BST. Inorder traversal gives sorted output.
Validate BST — Pass Min/Max Bounds
public boolean isValidBST(TreeNode root) { return validate(root, Long.MIN_VALUE, Long.MAX_VALUE); } private boolean validate(TreeNode node, long min, long max) { if (node == null) return true; if (node.val <= min || node.val >= max) return false; return validate(node.left, min, node.val) && validate(node.right, node.val, max); }
Kth Smallest in BST — Inorder Counting
int count = 0, result = -1; public int kthSmallest(TreeNode root, int k) { inorder(root, k); return result; } private void inorder(TreeNode node, int k) { if (node == null) return; inorder(node.left, k); if (++count == k) { result = node.val; return; } inorder(node.right, k); }
Classic BST Problems
  • Validate BST — pass min/max bounds down; use Long.MIN/MAX_VALUE to avoid int overflow
  • Kth Smallest Element in BST — inorder traversal, count to k
  • LCA of BST — simpler: if both p,q < root go left; if both > root go right; else current is LCA
  • Convert Sorted Array to BST — mid element is root, recurse on left and right halves

Java Tree Tips

  • Queue<TreeNode> q = new LinkedList<>() — for BFS (add children, poll one at a time)
  • Deque<TreeNode> stack = new ArrayDeque<>() — for iterative DFS (push/pop)
  • Always null-check before accessing .left or .right
  • For LCA: the two-pointer version for BST is O(log n); for general tree O(n)
  • Right side view = last node at each BFS level: if(i == size-1) result.add(node.val)
