Sorting & Searching — Coding Practice

Six classic interview problems — binary search and its rotated-array variants, merging, and interval problems. Real code, real hidden tests.

Binary search shows up far more than "search a sorted array" implies — three of these six problems are binary search wearing a disguise (rotated arrays, "find minimum"). Getting the boundary conditions exactly right (which half is guaranteed sorted, when to stop) is the actual skill being tested here, and a hidden test suite will catch off-by-one errors that a quick manual trace won't. Pick a language tab (JavaScript, TypeScript, Python, or Java — all four run for real in your browser), write the function, press Run Tests. Stuck? Use a hint, or jump to the Sorting & Searching visualizer for the underlying technique.
