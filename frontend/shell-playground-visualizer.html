Shell Playground

A working mini-shell with a real in-memory filesystem — type commands and watch them act. Flip between Bash, PowerShell, and CMD mode and the prompt, command names, and variable syntax change with it, so you can feel the differences between the three shells side by side. Try ls, cd projects, cat app/main.py.

🧪 This is a safe simulator, not your real OS — nothing here touches your machine. It implements a generous subset of each shell (navigation, files, pipes, redirection, variables) so the core muscle memory transfers. For the real thing, open a terminal alongside it.

The deep difference isn't the names — it's that Bash pipes text between commands, while PowerShell pipes objects. ls | ... in Bash passes lines of text; in PowerShell it passes FileInfo objects with real properties. See the PowerShell page for why that changes everything.
