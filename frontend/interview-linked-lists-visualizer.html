Linked Lists

Four pointer-manipulation patterns that cover every linked list interview problem.

ListNode class (used throughout)

class ListNode { int val; ListNode next; ListNode(int val) { this.val = val; } }
PATTERN 1

Fast & Slow Pointers (Floyd's)

Time: O(n) Space: O(1) Cycle detection, finding middle, kth from end
When to use: cycle detection (fast catches slow if cycle exists), finding the middle (fast hits end when slow is at middle), or kth element from end. Floyd's insight: in a cycle, a pointer moving 2x speed always catches a pointer moving 1x.
Fast & Slow Pointers — Cycle Detection
Click "Animate Cycle Detection" to see Floyd's algorithm on a list with a cycle.
Cycle Detection — Java
public boolean hasCycle(ListNode head) { ListNode slow = head, fast = head; while (fast != null && fast.next != null) { slow = slow.next; // move 1 step fast = fast.next.next; // move 2 steps if (slow == fast) return true; // they met → cycle } return false; // fast reached end → no cycle }
Find Cycle Entry (Linked List Cycle II)
public ListNode detectCycle(ListNode head) { ListNode slow = head, fast = head; while (fast != null && fast.next != null) { slow = slow.next; fast = fast.next.next; if (slow == fast) { // Reset one pointer to head, advance both 1 step at a time slow = head; while (slow != fast) { slow = slow.next; fast = fast.next; } return slow; // cycle entry point } } return null; }
Find Middle of Linked List
public ListNode middleNode(ListNode head) { ListNode slow = head, fast = head; while (fast != null && fast.next != null) { slow = slow.next; fast = fast.next.next; } return slow; // fast hit end → slow is at middle }
Classic Problems
  • Linked List Cycle — hasCycle: fast/slow meet if cycle exists
  • Linked List Cycle II — detectCycle: reset one to head after meeting, advance both by 1
  • Middle of Linked List — middleNode: slow at middle when fast hits null
PATTERN 2

In-Place Reversal

Time: O(n) Space: O(1) Reverse a list, palindrome check, reverse k-group
When to use: any problem requiring reversing all or part of a list. Three-pointer pattern: prev (reversed part), curr (current), next (saved before overwrite). The key step: curr.next = prev then advance all three pointers.
In-Place Reversal — Step by Step
Click Animate Reversal to watch the three-pointer swap.
Reverse Linked List — Iterative (O(1) space)
public ListNode reverseList(ListNode head) { ListNode prev = null, curr = head, next = null; while (curr != null) { next = curr.next; // 1. save next curr.next = prev; // 2. reverse the link prev = curr; // 3. advance prev curr = next; // 4. advance curr } return prev; // prev is now the new head }
Reverse Linked List — Recursive
public ListNode reverseList(ListNode head) { if (head == null || head.next == null) return head; ListNode newHead = reverseList(head.next); // reverse the rest head.next.next = head; // make next node point back at head head.next = null; // unlink head from rest return newHead; }
Palindrome Linked List
public boolean isPalindrome(ListNode head) { // 1. Find middle (fast/slow) ListNode slow = head, fast = head; while (fast != null && fast.next != null) { slow=slow.next; fast=fast.next.next; } // 2. Reverse second half ListNode prev = null, curr = slow; while (curr != null) { ListNode nx=curr.next; curr.next=prev; prev=curr; curr=nx; } // 3. Compare both halves ListNode l = head, r = prev; while (r != null) { if (l.val != r.val) return false; l = l.next; r = r.next; } return true; }
Classic Problems
  • Reverse Linked List — three-pointer iterative or recursive
  • Palindrome Linked List — find middle + reverse second half + compare
  • Reverse Nodes in k-Group — reverse k nodes at a time, reconnect groups
PATTERN 3

Merge & Sort

Merge: O(n+m)   Sort: O(n log n) Space: O(log n) for sort recursion Merge sorted lists, sort a linked list
When to use: merging two or more sorted lists (compare heads, take smaller), or sorting a linked list where merge sort is preferred over quicksort because random access is O(n). For merge K sorted lists, use a PriorityQueue with all list heads.
Merge Two Sorted Lists
public ListNode mergeTwoLists(ListNode l1, ListNode l2) { ListNode dummy = new ListNode(0), curr = dummy; while (l1 != null && l2 != null) { if (l1.val <= l2.val) { curr.next = l1; l1 = l1.next; } else { curr.next = l2; l2 = l2.next; } curr = curr.next; } curr.next = (l1 != null) ? l1 : l2; // attach remaining return dummy.next; }
Merge K Sorted Lists — PriorityQueue
public ListNode mergeKLists(ListNode[] lists) { PriorityQueue<ListNode> pq = new PriorityQueue<>((a,b) -> a.val - b.val); for (ListNode n : lists) if (n != null) pq.offer(n); ListNode dummy = new ListNode(0), curr = dummy; while (!pq.isEmpty()) { curr.next = pq.poll(); curr = curr.next; if (curr.next != null) pq.offer(curr.next); } return dummy.next; }
Sort Linked List — Merge Sort
public ListNode sortList(ListNode head) { if (head == null || head.next == null) return head; ListNode mid = getMid(head); ListNode right = mid.next; mid.next = null; // split return mergeTwoLists(sortList(head), sortList(right)); } private ListNode getMid(ListNode head) { ListNode slow = head, fast = head.next; // fast starts 1 ahead → slow stops before middle while (fast != null && fast.next != null) { slow=slow.next; fast=fast.next.next; } return slow; }
Classic Problems
  • Merge Two Sorted Lists — dummy head + compare and advance
  • Merge K Sorted Lists — PriorityQueue with initial heads, size O(k) at any time
  • Sort List — bottom-up merge sort, O(n log n) time O(log n) space
PATTERN 4

Dummy Node Pattern

Time: O(n) Space: O(1) Operations that might change the head node
When to use: any operation that might delete the head or insert before head. Create dummy.next = head, do all operations relative to dummy, return dummy.next. Also used in Remove Nth From End with two pointers n apart.

Click Animate to watch the two-pointer technique for removing nth from end.
Remove Nth Node From End — Java
public ListNode removeNthFromEnd(ListNode head, int n) { ListNode dummy = new ListNode(0); dummy.next = head; ListNode fast = dummy, slow = dummy; // advance fast n+1 steps ahead of slow for (int i = 0; i <= n; i++) fast = fast.next; // advance both until fast hits null while (fast != null) { slow = slow.next; fast = fast.next; } // slow.next is the node to delete slow.next = slow.next.next; return dummy.next; }
Classic Problems
  • Remove Nth From End — dummy head + two pointers n steps apart
  • Remove Linked List Elements — dummy simplifies removing head nodes
  • Swap Nodes in Pairs — dummy + swap every two adjacent nodes
  • Reorder List — find middle + reverse second half + merge two halves

Java Linked List Tips

  • while (curr != null) — standard traversal; check curr.next only after null check
  • if (curr != null && curr.next != null) — guard before two-step advance
  • Always use a dummy node when the head might change — avoids special-casing
  • new ListNode(0) — dummy sentinel; its val doesn't matter
  • Linked list merge sort is O(n log n) time O(log n) space — better than array merge sort's O(n) space
  • PriorityQueue comparator for ListNode: (a, b) -> a.val - b.val (safe since node values are usually bounded)
