1. Controlled vs Uncontrolled

Controlled — React owns the value

const [email, setEmail] = useState("");
<input
  value={email}
  onChange={e => setEmail(e.target.value)}
/>
// Every keystroke → setState → re-render
// Input ALWAYS shows state value

Pros: instant validation, conditional logic, derive other state. Cons: re-render on every keystroke — can be slow for large forms.

Uncontrolled — DOM owns the value

const emailRef = useRef();
<input ref={emailRef} defaultValue="" />
// Read value only when needed:
const value = emailRef.current.value;
// No re-renders on keystroke

Pros: no keystroke re-renders. Cons: harder to validate live, can get out of sync. React Hook Form is the best of both — refs under the hood, controlled API on top.

2. React Hook Form — The Right Way

const {
  register, handleSubmit,
  formState: { errors, isSubmitting }
} = useForm({ resolver: zodResolver(schema) });

// register() returns { ref, onChange, onBlur, name }
<input {...register("email", { required: true })} />
{errors.email && <span>{errors.email.message}</span>}
// handleSubmit validates then calls your fn
const onSubmit = async (data) => {
  // data is fully typed, validated
  await createUser(data);
};
<form onSubmit={handleSubmit(onSubmit)}>
  ...
  <button disabled={isSubmitting}>Save</button>
</form>

RHF uses uncontrolled refs internally — no re-render on keystroke. Only re-renders on submit or on validation changes. Orders of magnitude faster for large forms.

3. Zod Schema

const schema = z.object({
  email: z.string().email("Invalid email format"),
  password: z.string().min(8, "Min 8 characters").regex(/[A-Z]/, "Need uppercase"),
  confirmPassword: z.string(),
  age: z.number().min(18, "Must be 18+").max(120),
}).refine(data => data.password === data.confirmPassword, {
  message: "Passwords do not match",
  path: ["confirmPassword"], // attach error to this field
});

// TypeScript type is automatically inferred:
type UserForm = z.infer<typeof schema>;
// { email: string; password: string; confirmPassword: string; age: number }
Zod + React Hook Form = end-to-end type safety. The same schema can validate on the frontend and backend. z.infer<typeof schema> gives you a TypeScript type for free — no separate interface needed. Cross-field validation (password match) uses .refine().
