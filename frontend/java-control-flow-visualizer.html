Common Patterns & Pitfalls

// Pattern: early return — avoids deep nesting void process(User user) { if (user == null) return; if (!user.isActive()) return; if (!user.hasPermission()) return; // main logic at low nesting doWork(user); } // vs. "arrow" antipattern: void process(User user) { if (user != null) { if (user.isActive()) { if (user.hasPermission()) { doWork(user); // 3 levels deep! } } } }
// Pitfall: dangling else if (a > 0) if (b > 0) System.out.println("both positive"); else System.out.println("?"); // else belongs to inner if! use braces to be safe // Always use braces — even for one-liners if (cond) doA(); // easy to forget when adding line 2 doB(); // NOT in the if — always runs! // Better: if (cond) { doA(); }

Classic switch Statement (Java 1.0) — fallthrough by default

switch (day) { // int, String, char, enum case "MONDAY": case "TUESDAY": // fallthrough: no break needed System.out.println("Weekday"); break; // MUST break or falls to next case case "SATURDAY": case "SUNDAY": System.out.println("Weekend"); break; default: System.out.println("Other"); }
// Classic switch: what it can switch on // ✓ byte, short, int, char // ✓ Byte, Short, Integer, Character (wrappers) // ✓ String (Java 7+) // ✓ enum values // ✗ long, float, double, boolean, objects // Fallthrough example (intentional) switch (level) { case 3: bonus += 300; // falls through! case 2: bonus += 200; // falls through! case 1: bonus += 100; break; }

Modern switch Expression (Java 14+) — no fallthrough, returns a value

// Switch expression — yields a value, arrow syntax String label = switch (day) { case "MONDAY", "TUESDAY", "WEDNESDAY", "THURSDAY", "FRIDAY" -> "Weekday"; case "SATURDAY", "SUNDAY" -> "Weekend"; default -> "Unknown"; }; // No break needed — arrows don't fall through // Multiple values per case with comma // Compiler checks exhaustiveness for enums
// yield keyword — for multi-statement cases int points = switch (grade) { case "A" -> 4; case "B" -> 3; case "C" -> 2; case "D" -> 1; default -> { log("Invalid grade: " + grade); yield 0; // yield from block } }; // Pattern matching switch (Java 21) switch (obj) { case Integer i -> System.out.println("int: "+i); case String s -> System.out.println("str: "+s); case null -> System.out.println("null"); default -> System.out.println("other"); }

for loop — when you know the count

// Classic for: init; condition; update for (int i = 0; i < 5; i++) { System.out.println(i); // 0 1 2 3 4 } // Count down for (int i = 10; i >= 0; i -= 2) { System.out.print(i + " "); // 10 8 6 4 2 0 } // Multiple init/update for (int i = 0, j = 10; i < j; i++, j--) { System.out.println(i + "," + j); } // Infinite loop with break for (;;) { if (done) break; }
// Enhanced for (for-each) — iterate collections/arrays int[] nums = {1, 2, 3, 4, 5}; for (int n : nums) { System.out.print(n + " "); } List<String> names = List.of("Alice", "Bob"); for (String name : names) { System.out.println(name); } // Pitfall: can't modify index or use index // Use regular for if you need the index for (int i = 0; i < names.size(); i++) { System.out.println(i + ": " + names.get(i)); }

while & do-while — when count is unknown

// while — checks condition BEFORE each iteration int i = 0; while (i < 5) { System.out.println(i); i++; } // If i is already 5: zero iterations // Common: read until sentinel Scanner sc = new Scanner(System.in); String line; while (!(line = sc.nextLine()).isEmpty()) { process(line); }
// do-while — checks condition AFTER each iteration // Guaranteed to run at least once int n; do { n = getInput(); // prompts user until valid input } while (n < 1 || n > 10); // Menu loop example int choice; do { showMenu(); choice = sc.nextInt(); handleChoice(choice); } while (choice != 0); // 0 = exit

Choosing the Right Loop

for
Known iteration count, index needed, or iterating collection. Most common.
while
Condition-based, may run zero times (polling, reading input).
do-while
Must run at least once (menus, validation loops).

break — exit the loop immediately

// break exits the innermost loop for (int i = 0; i < 10; i++) { if (i == 5) break; // stops at 5 System.out.print(i + " "); // 0 1 2 3 4 } // Search pattern — find and stop int target = 42, foundAt = -1; for (int i = 0; i < arr.length; i++) { if (arr[i] == target) { foundAt = i; break; // no need to keep searching } }
// Labeled break — exit outer loop outer: for (int i = 0; i < 5; i++) { for (int j = 0; j < 5; j++) { if (matrix[i][j] == target) { found = true; break outer; // exits BOTH loops } } } // Continues here after break outer // break in switch — exits the switch switch (x) { case 1: doA(); break; // no fallthrough case 2: doB(); break; }

continue — skip current iteration

// continue skips the rest of this iteration for (int i = 0; i < 10; i++) { if (i % 2 == 0) continue; // skip evens System.out.print(i + " "); // 1 3 5 7 9 } // Filter and process pattern for (User user : users) { if (!user.isActive()) continue; if (user.getAge() < 18) continue; sendEmail(user); }
// Labeled continue — skip to next outer iteration outer: for (int i = 0; i < 3; i++) { for (int j = 0; j < 3; j++) { if (j == 1) continue outer; System.out.println(i + "," + j); } } // Prints: 0,0 1,0 2,0 // (j=1 triggers skip of rest of inner loop) // return — exits the entire method for (Order o : orders) { if (o.isFulfilled()) return true; } return false;
