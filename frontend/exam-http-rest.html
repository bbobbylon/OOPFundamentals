HTTP & REST APIs — Practice Exam

A pool of questions across HTTP basics, methods & idempotency, status codes, REST resource design, headers & content negotiation, caching, and API security.

HTTP is stateless and verb-driven; REST maps your domain to resources you act on with those verbs. The questions that trip people up: which methods are safe vs idempotent (GET/PUT/DELETE yes, POST no), choosing the right status code (201 + Location, 401 vs 403, 409 vs 422, 429), and how caching (ETag → 304) and CORS preflight actually work. Every option is written to be plausible — the distractors are real misconceptions, not filler — so you can't guess by length. Practice mode links each answer to the visualizer that proves it. Drill until the bars are green on the dashboard.
