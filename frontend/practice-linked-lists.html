Linked Lists — Coding Practice

Six classic interview problems — real pointer manipulation, not array shortcuts. Real code, real hidden tests.

These exercises hand you an actual linked list, not an array. Tests are written as a plain array like [1, 2, 3] for convenience, but before your function runs, this page builds a REAL chain of linked { val, next } nodes out of it — the same shape a technical interview gives you — and your function receives the head node, not the array. Whatever node (or chain of nodes) you return gets walked and converted back to an array automatically to check your answer, so you never have to worry about the grading format — just solve it the way you would on a whiteboard, by following .next pointers.

Need to build a brand-new node yourself (a couple of these problems do)? In JavaScript/TypeScript that's a plain object: { val: x, next: null }. In Python, a ListNode class is already provided in the starter code for you to instantiate. Pick a language tab, write the function, press Run Tests. Stuck? Use a hint, or jump to the Linked Lists visualizer for the underlying technique.
