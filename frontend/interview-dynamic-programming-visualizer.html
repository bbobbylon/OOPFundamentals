Dynamic Programming

Patterns, animated tables, and classic problems — from 1D sequences to 2D grids to knapsack.

🧩 What are the DP interview patterns — and how do you recognize which of the 6 core DP templates applies to a given problem?

Dynamic programming interview problems are solved by recognizing a pattern, applying the matching template, and filling in the state/recurrence/base case. There are roughly 6 patterns that cover ~90% of DP problems. 1D Linear DP: dp[i] depends on dp[i-1] or dp[i-2] (or a few previous states). Classic: Climbing Stairs (dp[i] = dp[i-1] + dp[i-2]), House Robber (dp[i] = max(dp[i-1], dp[i-2] + nums[i])). State: position in array. Can usually be space-optimized to O(1) by keeping only the last few values. 2D Grid DP: dp[i][j] = ways/minimum cost to reach cell (i,j). Classic: Unique Paths (dp[i][j] = dp[i-1][j] + dp[i][j-1]), Minimum Path Sum, Triangle. State: row + column. String DP (2D): dp[i][j] involves substrings of two strings. Classic: Longest Common Subsequence (dp[i][j] = chars match → dp[i-1][j-1]+1, else max(dp[i-1][j], dp[i][j-1])), Edit Distance (Levenshtein), Longest Palindromic Subsequence. State: indices into both strings. Interval DP: dp[i][j] = optimal cost over a subarray/subrange. Classic: Burst Balloons, Minimum Cost to Merge Stones. State: left and right endpoints of the interval. Build from small intervals to larger ones. 0/1 Knapsack: include or exclude each item. Classic: Partition Equal Subset Sum, Target Sum, Coin Change (unbounded variant). State: index + remaining capacity. dp[i][w] = max value using first i items with weight limit w. State Machine DP: each dp[i] = one of several states with transitions between them. Classic: Best Time to Buy and Sell Stock (state: holding or not holding stock), House Robber (adjacent houses), Sticker-based problems. How to identify DP: problem asks for min/max/count/true-or-false over many decisions; decisions affect future options; brute force is exponential but there are overlapping subproblems. Start with the brute force recursive solution → add memoization → optionally convert to tabulation.

House Robber (1D DP)

// House Robber: max money without robbing adjacent houses // Decision: rob house i (get nums[i]) OR skip house i // dp[i] = max money using houses 0..i // Recurrence: // If rob house i: dp[i] = dp[i-2] + nums[i] (can't rob i-1) // If skip house i: dp[i] = dp[i-1] (best without i) // dp[i] = max(dp[i-1], dp[i-2] + nums[i]) // Base cases: dp[0] = nums[0], dp[1] = max(nums[0], nums[1]) // Answer: dp[n-1] int rob(int[] nums) { if (nums.length == 1) return nums[0]; int prev2 = nums[0]; int prev1 = Math.max(nums[0], nums[1]); for (int i=2; i<nums.length; i++) { int cur = Math.max(prev1, prev2 + nums[i]); prev2 = prev1; prev1 = cur; // space-optimized: O(1) space } return prev1; // O(n) time, O(1) space } // State machine view: 2 states (rob this / skip this) // transition: skip→rob or skip→skip (never rob→rob)

Coin Change (Knapsack)

// Coin Change: fewest coins to make amount // "Unbounded knapsack" — can use each coin unlimited times // State: dp[i] = minimum coins to make exactly amount i // Recurrence: dp[i] = min(dp[i-coin]+1) for each coin // if (i-coin >= 0 and dp[i-coin] != INF) // Base: dp[0] = 0 (0 coins to make amount 0) // Answer: dp[amount] (or -1 if still INF) int coinChange(int[] coins, int amount) { int[] dp = new int[amount + 1]; Arrays.fill(dp, amount + 1); // INF = impossible dp[0] = 0; // base case for (int i = 1; i <= amount; i++) { for (int coin : coins) { if (i - coin >= 0) { // can use this coin dp[i] = Math.min(dp[i], dp[i - coin] + 1); } } } return dp[amount] > amount ? -1 : dp[amount]; } // O(amount * coins) time, O(amount) space

LCS (2D String DP)

// Longest Common Subsequence // Foundation for: Edit Distance, Diff algorithms // State: dp[i][j] = LCS of s1[0..i-1] and s2[0..j-1] // Recurrence: // s1[i-1]==s2[j-1]: dp[i][j] = dp[i-1][j-1] + 1 // else: dp[i][j] = max(dp[i-1][j], dp[i][j-1]) // Base: dp[0][j] = dp[i][0] = 0 (empty string) int lcs(String s1, String s2) { int m=s1.length(), n=s2.length(); int[][] dp = new int[m+1][n+1]; for (int i=1;i<=m;i++) for (int j=1;j<=n;j++) { if (s1.charAt(i-1)==s2.charAt(j-1)) dp[i][j] = dp[i-1][j-1]+1; // chars match else dp[i][j] = Math.max(dp[i-1][j],dp[i][j-1]); // skip one } return dp[m][n]; // O(m*n) time + space } // Edit Distance = LCS extended: // replace = dp[i-1][j-1]+1, insert=dp[i][j-1]+1, delete=dp[i-1][j]+1

Interview / Context: DP is one of the hardest interview topics and one of the most rewarding to master. The critical insight: stop trying to "figure out DP" from scratch on each problem. Instead, memorize the 6 patterns, recognize which pattern the current problem fits, and apply the template. For the interview: when you encounter a DP problem, announce: "This looks like a [1D linear / knapsack / 2D string] DP problem because [reason]. I'll define my state as dp[i] = [meaning], my recurrence as [formula], base case as [value], and the answer is [dp[...]]. Let me code the tabulation." This structured approach signals senior-level thinking even if you make a small implementation mistake.

INTRO

What is Dynamic Programming?

Two requirements: (1) Overlapping subproblems — the same subproblem appears multiple times in the recursion tree. (2) Optimal substructure — the optimal solution can be built from optimal solutions to subproblems.

Top-down (memoization): recursive + cache. Start from the original problem. Easier to write, may not fill all states.
Bottom-up (tabulation): iterative + dp array. Fill from base cases up. Usually more efficient (no recursion overhead).

The key question: "What information do I need to fully describe a subproblem?" That becomes your state. Then ask: "If I knew the answer for all smaller subproblems, how would I compute this one?" That's your recurrence.

House Robber — Java
public int rob(int[] nums) { int prev2 = 0, prev1 = 0; for (int num : nums) { int curr = Math.max(prev1, prev2 + num); prev2 = prev1; prev1 = curr; } return prev1; // space-optimized: only keep last two values }
Climbing Stairs (Fibonacci pattern)
public int climbStairs(int n) { if (n <= 2) return n; int prev2 = 1, prev1 = 2; for (int i = 3; i <= n; i++) { int curr = prev1 + prev2; prev2 = prev1; prev1 = curr; } return prev1; }
Classic Problems
  • Climbing Stairs — dp[i] = dp[i-1] + dp[i-2]; space-optimize to 2 variables
  • House Robber — dp[i] = max(dp[i-1], dp[i-2] + nums[i])
  • Maximum Subarray (Kadane's) — dp[i] = max(nums[i], dp[i-1] + nums[i])
  • Jump Game — greedy/DP: track furthest reach; can we reach the last index?

2D DP — Grids & Two Sequences

Unique Paths — dp[i][j] = dp[i-1][j] + dp[i][j-1]

Unique Paths
public int uniquePaths(int m, int n) { int[] dp = new int[n]; Arrays.fill(dp, 1); // first row: 1 way to reach each cell (go right) for (int i = 1; i < m; i++) for (int j = 1; j < n; j++) dp[j] += dp[j - 1]; // from above (dp[j]) + from left (dp[j-1]) return dp[n - 1]; }
Longest Common Subsequence (LCS)
public int longestCommonSubsequence(String text1, String text2) { int m = text1.length(), n = text2.length(); int[][] dp = new int[m + 1][n + 1]; for (int i = 1; i <= m; i++) for (int j = 1; j <= n; j++) { if (text1.charAt(i-1) == text2.charAt(j-1)) dp[i][j] = dp[i-1][j-1] + 1; // chars match: extend else dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]); // skip one char } return dp[m][n]; }
Classic Problems
  • Unique Paths — dp[i][j] = from_above + from_left; space-optimize to 1D
  • Minimum Path Sum — same recurrence, add grid[i][j] to min(above, left)
  • Longest Common Subsequence — 2D table, match extends diagonal, mismatch takes max of skip-left or skip-up
PATTERN 3

Knapsack — Include / Exclude Decision

Time: O(n×W) Space: O(W) Subset selection, coin change, target sum
Core pattern: for each item, decide include or exclude. dp[i][w] = max(exclude=dp[i-1][w], include=dp[i-1][w-weight]+value). For coin change (unbounded), use 1D: dp[amount] = min over all coins of dp[amount-coin]+1.

Coin Change — Java (Bottom-Up)
public int coinChange(int[] coins, int amount) { int[] dp = new int[amount + 1]; Arrays.fill(dp, amount + 1); // infinity = impossible dp[0] = 0; // base case: 0 coins for 0 amount for (int a = 1; a <= amount; a++) for (int coin : coins) if (coin <= a) dp[a] = Math.min(dp[a], dp[a - coin] + 1); return dp[amount] > amount ? -1 : dp[amount]; }
0/1 Knapsack
public int knapsack(int[] weights, int[] values, int capacity) { int n = weights.length; int[] dp = new int[capacity + 1]; for (int i = 0; i < n; i++) for (int w = capacity; w >= weights[i]; w--) // iterate BACKWARDS for 0/1 dp[w] = Math.max(dp[w], dp[w - weights[i]] + values[i]); return dp[capacity]; }
Classic Problems
  • Coin Change — unbounded knapsack; iterate forwards; dp[a] = min coins
  • Partition Equal Subset Sum — subset sum: can we reach sum/2? Same as 0/1 knapsack
  • Target Sum — assign +/- to each number: count subsets summing to (total+target)/2
PATTERN 4

String DP

Time: O(m×n) or O(n²) Space: O(m×n) → O(n) Edit distance, palindromes, word break
Edit Distance
public int minDistance(String word1, String word2) { int m = word1.length(), n = word2.length(); int[][] dp = new int[m + 1][n + 1]; for (int i = 0; i <= m; i++) dp[i][0] = i; // delete all of word1 for (int j = 0; j <= n; j++) dp[0][j] = j; // insert all of word2 for (int i = 1; i <= m; i++) for (int j = 1; j <= n; j++) { if (word1.charAt(i-1) == word2.charAt(j-1)) dp[i][j] = dp[i-1][j-1]; else dp[i][j] = 1 + Math.min(dp[i-1][j], // delete Math.min(dp[i][j-1], // insert dp[i-1][j-1])); // replace } return dp[m][n]; }
Word Break
public boolean wordBreak(String s, List<String> wordDict) { Set<String> dict = new HashSet<>(wordDict); boolean[] dp = new boolean[s.length() + 1]; dp[0] = true; // empty string is breakable for (int i = 1; i <= s.length(); i++) for (int j = 0; j < i; j++) if (dp[j] && dict.contains(s.substring(j, i))) { dp[i] = true; break; } return dp[s.length()]; }
Classic Problems
  • Edit Distance — if chars match: free diagonal; else 1 + min(delete, insert, replace)
  • Longest Palindromic Substring — expand around center O(n²) or dp[i][j] = is substring palindrome
  • Word Break — dp[i] = can s[0..i] be broken? Try all split points j

DP Problem-Solving Strategy

  • Draw the recursion tree first — spot repeated subproblems
  • Define state clearly: what parameters fully describe a subproblem?
  • Write the recurrence in plain English before code: "dp[i] is the max money I can rob from houses 0 to i"
  • Identify base cases: dp[0], dp[1] (1D); dp[0][j]=j, dp[i][0]=i (2D with string prefix)
  • Space optimization: if dp[i] only depends on dp[i-1] and dp[i-2], use 2 variables
  • For 0/1 knapsack: iterate weights backwards to prevent reusing items
  • For unbounded knapsack (coin change): iterate forwards to allow reuse
