SQL — Practice Exam

A pool of questions across SELECT & filtering, joins, aggregation, keys & constraints, indexes, transactions (ACID/isolation), normalization, and PostgreSQL internals & scale (JSONB, VACUUM, pooling, replication, partitioning/sharding).

SQL is declarative: you say WHAT rows you want, the engine decides how to get them. The traps that separate juniors from seniors: the logical order of evaluation (WHERE before GROUP BY before HAVING), why a filter in the WHERE clause silently turns a LEFT JOIN back into an INNER JOIN, three-valued NULL logic, and when an index actually gets used. Practice mode links each answer to the visualizer that proves it — and there’s a live SQL playground if you want to run queries. Drill until the bars are green on the dashboard.
