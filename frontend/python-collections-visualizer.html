Python Collections & Comprehensions

Lists, dicts, sets, tuples — their internals, comprehensions, sorting, and the iteration protocol that ties them all together.

🗃️ What are Python's built-in collections — and when do you pick each one?

Python ships four core collections: list (ordered, mutable, O(1) append/index, O(n) insert/search), dict (ordered hash map, O(1) get/set, hashable keys), set (unique hashable values, O(1) membership, set algebra), and tuple (immutable, hashable — usable as a dict key). Comprehensions build them concisely ([x for x in xs if …]), and generator expressions do it lazily (O(1) memory). Any object with __iter__/__next__ works in a for loop — which is how custom pagination cursors become iterables.

  • Pick by access pattern — list (order), dict (lookup), set (membership/dedupe), tuple (fixed/hashable).
  • dict/set are O(1); list in/insert are O(n).
  • Comprehensions are the idiom — list/dict/set, plus lazy generator expressions.
  • The iteration protocol is extensible — __iter__/__next__ makes anything loopable.

1. Comprehension Anatomy

Comprehensions are the most Pythonic way to build collections. They all follow the same grammar: expression for item in iterable if condition.

[x*x for x in range(10) if x % 2 == 0]

All four flavors

# List comprehension → list
evens = [x*x for x in range(10) if x%2==0]

# Dict comprehension → dict
lengths = {w: len(w) for w in words}

# Set comprehension → set (no dups)
unique = {x%5 for x in nums}

# Generator expression → lazy iterator
gen = (x*x for x in range(1_000_000))
# () wrapping = generator; no memory spike

Nested comprehensions

# Flatten a matrix
matrix = [[1,2],[3,4],[5,6]]
flat = [n for row in matrix for n in row]
# [1, 2, 3, 4, 5, 6]

# Transposition
transposed = [
    [row[i] for row in matrix]
    for i in range(len(matrix[0]))
]

2. The Iteration Protocol

Everything iterable in Python implements __iter__ returning an iterator, and __next__ advancing it. for x in obj calls these implicitly.

Custom iterator

class Countdown:
    def __init__(self, n): self.n = n
    def __iter__(self): return self
    def __next__(self):
        if self.n < 0: raise StopIteration
        result = self.n
        self.n -= 1
        return result

for n in Countdown(3): print(n)
# 3, 2, 1, 0

Generator functions (simpler)

def countdown(n):
    while n >= 0:
        yield n
        n -= 1

# yield suspends the function, returns value,
# resumes on next() call — lazy by default
gen = countdown(1_000_000)
next(gen)  # 1000000 — only computed on demand

# itertools for powerful combinations
from itertools import islice, chain
list(islice(countdown(10), 3))  # [10, 9, 8]

3. Sorting, Defaultdict & Counter

# sorted() with key — most powerful Python sort trick
people = [("Alice", 30), ("Bob", 25), ("Cara", 28)]
sorted(people, key=lambda p: p[1])
# [("Bob", 25), ("Cara", 28), ("Alice", 30)]

# Stable sort — ties keep original order
sorted(people, key=lambda p: p[1], reverse=True)

from collections import defaultdict, Counter

# defaultdict — no KeyError on missing keys
groups = defaultdict(list)
for name, dept in employees:
    groups[dept].append(name)

# Counter — frequency counting
c = Counter("mississippi")
c.most_common(3)  # [("s", 4), ("i", 4), ("p", 2)]
