Python Collections & Comprehensions

Lists, dicts, sets, tuples — their internals, comprehensions, sorting, and the iteration protocol that ties them all together.

What are Python's built-in collections — and when do you pick each one?

Python ships four essential built-in collection types, each with different performance characteristics and use cases. list: an ordered, mutable sequence backed by a dynamic array. O(1) append/index, O(n) insert/search. Use for: ordered data, stacks (append/pop from end), any sequence where order matters. dict: an ordered (Python 3.7+) key-value mapping backed by a hash table. O(1) average get/set/delete. Keys must be hashable (strings, numbers, tuples). Use for: fast lookups, counting, mapping IDs to objects, JSON-like data. set: an unordered collection of unique hashable values backed by a hash table. O(1) add/remove/membership test. Supports union (|), intersection (&), difference (-). Use for: deduplication, fast membership testing. tuple: an ordered, IMMUTABLE sequence. Faster than list, smaller memory, hashable (can be a dict key). Use for: returning multiple values, fixed records. Comprehensions: Python's concise syntax for building collections from iterables — [x*2 for x in range(10) if x % 2 == 0]. List comprehension, dict comprehension {k: v for k, v in items}, set comprehension {x for x in values}, and generator expression (x*2 for x in range(10)) (lazy, memory-efficient — processes one item at a time). Iteration protocol: any object implementing __iter__ (returns an iterator) and __next__ (returns next value, raises StopIteration when done) works with for loops, list(), sum(), and all built-in functions. This protocol is what makes custom pagination cursors work as iterables.

# Custom iterator for paginated API class UserCursor: def __init__(self, client, page_size=100): self.client = client self.cursor = None self.buffer = [] self.page_size = page_size def __iter__(self): return self def __next__(self): if not self.buffer: page = self.client.list_users( cursor=self.cursor, size=self.page_size ) self.buffer = page.users self.cursor = page.next_cursor if not self.buffer: raise StopIteration return self.buffer.pop(0) # Works in for loops, list(), sum(), etc: for user in UserCursor(ping_client): provision_user(user) all_users = list(UserCursor(ping_client))

1. Comprehension Anatomy

Comprehensions are the most Pythonic way to build collections. They all follow the same grammar: expression for item in iterable if condition.

[x*x for x in range(10) if x % 2 == 0]

All four flavors

# List comprehension → list
evens = [x*x for x in range(10) if x%2==0]

# Dict comprehension → dict
lengths = {w: len(w) for w in words}

# Set comprehension → set (no dups)
unique = {x%5 for x in nums}

# Generator expression → lazy iterator
gen = (x*x for x in range(1_000_000))
# () wrapping = generator; no memory spike

Nested comprehensions

# Flatten a matrix
matrix = [[1,2],[3,4],[5,6]]
flat = [n for row in matrix for n in row]
# [1, 2, 3, 4, 5, 6]

# Transposition
transposed = [
    [row[i] for row in matrix]
    for i in range(len(matrix[0]))
]

2. The Iteration Protocol

Everything iterable in Python implements __iter__ returning an iterator, and __next__ advancing it. for x in obj calls these implicitly.

Custom iterator

class Countdown:
    def __init__(self, n): self.n = n
    def __iter__(self): return self
    def __next__(self):
        if self.n < 0: raise StopIteration
        result = self.n
        self.n -= 1
        return result

for n in Countdown(3): print(n)
# 3, 2, 1, 0

Generator functions (simpler)

def countdown(n):
    while n >= 0:
        yield n
        n -= 1

# yield suspends the function, returns value,
# resumes on next() call — lazy by default
gen = countdown(1_000_000)
next(gen)  # 1000000 — only computed on demand

# itertools for powerful combinations
from itertools import islice, chain
list(islice(countdown(10), 3))  # [10, 9, 8]

3. Sorting, Defaultdict & Counter

# sorted() with key — most powerful Python sort trick
people = [("Alice", 30), ("Bob", 25), ("Cara", 28)]
sorted(people, key=lambda p: p[1])
# [("Bob", 25), ("Cara", 28), ("Alice", 30)]

# Stable sort — ties keep original order
sorted(people, key=lambda p: p[1], reverse=True)

from collections import defaultdict, Counter

# defaultdict — no KeyError on missing keys
groups = defaultdict(list)
for name, dept in employees:
    groups[dept].append(name)

# Counter — frequency counting
c = Counter("mississippi")
c.most_common(3)  # [("s", 4), ("i", 4), ("p", 2)]
