Autocomplete · insert/search/startsWith · compressed radix tries · real-world applications

What Is a Trie?

A trie (from retrieval, pronounced "try") is a tree where each node represents a character, and paths from root to marked nodes spell out stored words. Lookup time is proportional to the length of the key, not the number of stored words.

Inserting "cat", "car", "card", "care", "bat"

root
├── c
│ └── a
│ ├── t [end] "cat"
│ └── r [end] "car"
│ ├── d [end] "card"
│ └── e [end] "care"
└── b
└── a
└── t [end] "bat"

Nodes marked [end] = isEndOfWord = true. Shared prefixes ("ca", "car") occupy a single node.

Insert

// Insert "apple" into trie // Walk from root, create nodes as needed void insert(String word) { TrieNode node = root; for (char ch : word.toCharArray()) { int idx = ch - 'a'; // 0-25 for a-z if (node.children[idx] == null) node.children[idx] = new TrieNode(); node = node.children[idx]; } node.isEnd = true; // mark word boundary } // Trace for "apple": // root → a(new) → p(new) → p(new) → l(new) → e(new,isEnd=true) // Insert "app" next: // root → a(exists) → p(exists) → p(exists,isEnd=true) // Only marks isEnd, shares first 3 nodes
Key insight: When you insert "apple" then "app", only the 'p' node at depth 3 gets its isEnd flag changed. No new nodes are created — prefix sharing is automatic.

Search & startsWith

// search(word): must exist AND isEnd == true boolean search(String word) { TrieNode node = root; for (char ch : word.toCharArray()) { int idx = ch - 'a'; if (node.children[idx] == null) return false; node = node.children[idx]; } return node.isEnd; // "car" in "card" trie → isEnd on 'r'? } // startsWith(prefix): path exists, isEnd doesn't matter boolean startsWith(String prefix) { TrieNode node = root; for (char ch : prefix.toCharArray()) { int idx = ch - 'a'; if (node.children[idx] == null) return false; node = node.children[idx]; } return true; // prefix exists somewhere in trie }
// Autocomplete: find all words with given prefix List<String> autocomplete(String prefix) { TrieNode node = root; for (char ch : prefix.toCharArray()) { int idx = ch - 'a'; if (node.children[idx] == null) return List.of(); node = node.children[idx]; } // DFS from here, collect all end nodes List<String> results = new ArrayList<>(); dfs(node, new StringBuilder(prefix), results); return results; } void dfs(TrieNode n, StringBuilder sb, List<String> res) { if (n.isEnd) res.add(sb.toString()); for (int i = 0; i < 26; i++) { if (n.children[i] != null) { sb.append((char)('a' + i)); dfs(n.children[i], sb, res); sb.deleteCharAt(sb.length()-1); // backtrack } } }

Delete

// Delete with pruning — remove unused nodes // Returns true if node can be deleted (no children, not end) boolean delete(TrieNode node, String word, int depth) { if (node == null) return false; if (depth == word.length()) { if (!node.isEnd) return false; // word not in trie node.isEnd = false; return !node.hasChildren(); // safe to delete if leaf } int idx = word.charAt(depth) - 'a'; if (delete(node.children[idx], word, depth+1)) { node.children[idx] = null; // prune child return !node.isEnd && !node.hasChildren(); } return false; }

Delete Cases

Case 1: Leaf word. "card" has no children → unmark isEnd AND delete 'd' node, then 'r' if 'r' only had 'd' → etc up to shared prefix.
Case 2: Shared prefix. Deleting "car" when "card" exists → only unmark isEnd on 'r'. Don't delete 'r' node.
Case 3: Prefix of another word. Deleting "app" when "apple" exists → just unmark isEnd on second 'p'. Path stays.

Full Trie Implementation (Java)

class Trie { private static class TrieNode { TrieNode[] children = new TrieNode[26]; // a-z boolean isEnd; boolean hasChildren() { for (TrieNode c : children) if (c != null) return true; return false; } } private final TrieNode root = new TrieNode(); public void insert(String word) { TrieNode node = root; for (char ch : word.toCharArray()) { int i = ch - 'a'; if (node.children[i] == null) node.children[i] = new TrieNode(); node = node.children[i]; } node.isEnd = true; } public boolean search(String word) { TrieNode node = find(word); return node != null && node.isEnd; } public boolean startsWith(String prefix) { return find(prefix) != null; } private TrieNode find(String s) { TrieNode node = root; for (char ch : s.toCharArray()) { int i = ch - 'a'; if (node.children[i] == null) return null; node = node.children[i]; } return node; } public List<String> autocomplete(String prefix) { TrieNode node = find(prefix); List<String> results = new ArrayList<>(); if (node != null) dfs(node, new StringBuilder(prefix), results); return results; } private void dfs(TrieNode n, StringBuilder sb, List<String> res) { if (n.isEnd) res.add(sb.toString()); for (int i = 0; i < 26; i++) { if (n.children[i] != null) { sb.append((char)('a' + i)); dfs(n.children[i], sb, res); sb.deleteCharAt(sb.length() - 1); } } } } // Usage: Trie t = new Trie(); t.insert("apple"); t.insert("app"); t.insert("application"); t.search("app"); // true t.search("ap"); // false (not inserted) t.startsWith("app"); // true t.autocomplete("app"); // ["app", "apple", "application"]

HashMap-based Trie (Unicode Support)

// Use HashMap instead of fixed 26-element array // Supports any character set: unicode, numbers, symbols class TrieNode { Map<Character, TrieNode> children = new HashMap<>(); boolean isEnd; } void insert(String word) { TrieNode node = root; for (char ch : word.toCharArray()) { node = node.children.computeIfAbsent(ch, k -> new TrieNode()); } node.isEnd = true; } // Tradeoff: more flexible, but slower (HashMap overhead vs array index) // Array[26]: O(1) child lookup HashMap: O(1) average but higher constant

Radix Trie (Compressed Trie)

A radix trie collapses chains of single-child nodes into a single edge labeled with a string. This dramatically reduces node count when words don't share many prefixes. Used in IP routing (Patricia trie), URL routers, and DNS.

Standard Trie — "test", "team", "toaster"

root
└── t
├── e
│ ├── s
│ │ └── t [end]
│ └── a
│ └── m [end]
└── o
└── a
└── s
└── t
└── e
└── r [end]
12 nodes total

Radix Trie — same words, compressed

root
└── "t"
├── "e"
│ ├── "st" [end] → "test"
│ └── "am" [end] → "team"
└── "oaster" [end] → "toaster"

4 nodes — 67% fewer!
Edges hold strings, not just characters

Radix Trie Applications

IP Routing — Longest Prefix Match

// Router stores network prefixes in a radix trie // 192.168.0.0/16 → interface eth0 // 192.168.1.0/24 → interface eth1 // 10.0.0.0/8 → interface eth2 // For packet to 192.168.1.55: // Walk trie with bits of dest IP // Find LONGEST matching prefix → eth1 // Binary trie: left=0, right=1 // Java: no built-in radix trie // Libraries: Apache Commons Collections // (PatriciaTrie for String key routing)

HTTP Router (web frameworks)

// Express.js, Go's httprouter, Gin // store URL paths in a radix trie // Routes registered: // GET /users/:id // GET /users/:id/posts // GET /users/me ← static, wins over :id // Radix trie finds the right handler // in O(url_length) instead of O(routes × url_length) // Spring Boot uses AntPathMatcher (less efficient) // Spring 6 / Boot 3 uses PathPatternParser // (radix-like pattern matching)

Real-World Applications

Autocomplete / Search Suggestions

Google, IDE autocomplete, phone keyboard. Insert all valid words; on each keystroke, call startsWith(prefix) then DFS to collect top-N suggestions. Can add frequency weights to TrieNode and return most frequent results first.

// Frequency-weighted node class TrieNode { TrieNode[] ch = new TrieNode[26]; boolean isEnd; int frequency; // how often word appears } // Sort autocomplete results by frequency desc

Spell Checker

Load dictionary into trie. For a misspelled word, generate candidates by BFS with limited edit distance. Levenshtein automata can combine with trie for O(n × |alphabet| × |word|) spell correction.

// Fuzzy search: allow 1 typo void fuzzySearch(TrieNode n, char[] word, int pos, int errors) { if (errors > maxErrors) return; if (pos == word.length && n.isEnd) addResult(); // Try correct char OR skip (edit distance) }

Word Game Solver

Boggle, Scrabble: explore all letter paths on the board via backtracking, pruning immediately when no word in dictionary starts with current prefix. Without trie, you'd check every path against every dictionary word.

DNS Resolution

DNS uses a hierarchical trie: root → TLD (.com) → domain (google) → subdomain (mail). Each level is a separate zone. Lookups walk down the tree, delegating to different servers at each level.

Aho-Corasick — Multi-Pattern Search

Search a text for multiple patterns simultaneously in O(text + matches) time. Used in network intrusion detection (Snort), DNA sequence search, grep -F (fixed string matching).

// Aho-Corasick = Trie + failure links (like KMP) // Build phase: O(total pattern length) // Search phase: O(text length + number of matches) // 1. Insert all patterns into trie // 2. Build failure links (BFS) // fail[node] = longest proper suffix of node's // string that is a prefix of any pattern // 3. Search: follow transitions, on mismatch // follow failure link (don't restart from root) // Example: patterns = ["he","she","his","hers"] // Text: "ushers" // Finds: "she" at pos 1, "he" at pos 2, "hers" at pos 2 // All in ONE pass through the text!
Why it matters: Without Aho-Corasick, searching for K patterns in text of length N costs O(N × K × avg_pattern_length). With it: O(N + total_matches) after O(total_pattern_chars) build time.
