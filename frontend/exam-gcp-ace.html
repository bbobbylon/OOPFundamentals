Google Cloud Associate Cloud Engineer (ACE) — Practice Exam

Questions across projects & IAM, Compute Engine, GKE, Cloud Run & Functions, Cloud Storage, Cloud SQL / Firestore / BigQuery, and IAM / Secret Manager / Workload Identity Federation — the ACE core.

The mental model: everything sits inside a project, every action is gated by IAM twice — once by API enablement, once by a role binding — and identity flows outward through service accounts, never through downloaded keys. ACE rewards knowing WHICH compute product fits a scenario (Compute Engine vs GKE vs Cloud Run vs Cloud Functions), how a Managed Instance Group keeps a fleet healthy without manual intervention, and the sharp edges: IAM bindings are a pure union with no explicit Deny, Spot VMs give a ~30-second eviction notice, and Workload Identity Federation replaces every long-lived service-account key with a short-lived token exchange. Practice mode links every answer to the visualizer that walks the exact flow. Drill until the bars are green on the dashboard.
