1. Props essentials

type ButtonProps = {
  label: string;
  onClick: () => void;
  variant?: 'primary' | 'ghost'; // optional + a union (not just string)
  children?: React.ReactNode; // anything renderable
};
function Button({ label, onClick, variant = 'primary' }: ButtonProps) { … }

3. The React.FC debate

Prefer a plain function with a typed props parameter over React.FC. React.FC historically forced an implicit children prop (even for components that take none), complicates generics, and adds little. The community-recommended style is function Comp(props: Props) {} or const Comp = (props: Props) => {} and declare children explicitly when you want it.
