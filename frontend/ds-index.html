1 Foundational — linear structures

Master the simplest structures first: arrays, linked lists, stacks, and queues. These appear in every system and form the building blocks of everything else.

Static arrays, ArrayList internals, amortized growth, 2D arrays, and when to choose array over linked list. Includes ArrayDeque as a circular buffer.

Singly, doubly, and circular linked lists. Pointer manipulation, sentinel nodes, common interview problems (reverse, detect cycle, find middle), and Java's LinkedList.

2 Core — trees, heaps & hash tables

The structures that power databases, operating systems, and compilers. Trees give you logarithmic search; heaps give you priority; hash tables give you constant-time lookup.

Trees — Binary, BST, AVL, Red-Black

Binary tree traversals, BST operations, AVL rotations for balance, Red-Black tree rules, and B-Trees (how databases store indexes). Interactive insert/delete animations.

BST · AVL · Red-Black · B-Tree · traversals

Heaps & Priority Queues

Min-heap and max-heap array representation, the heapify operation, heap sort, Java PriorityQueue internals, and real-world uses: Dijkstra, task scheduling, top-K problems.

min-heap · max-heap · heapify · PriorityQueue

Hash Tables — Deep Dive

Hash functions, collision resolution (chaining vs open addressing), load factor, rehashing, and how Java's HashMap really works under the hood including treeified buckets.

hash function · chaining · open addressing · rehash

3 Advanced — graphs, tries & disjoint sets

Structures that model real-world relationships: networks, dictionaries, union-find. Used in routing, autocomplete, social graphs, and version control.

Graphs — Weighted, Dijkstra & More

Directed vs undirected, adjacency matrix vs list, topological sort, Dijkstra's shortest path, Bellman-Ford (negative edges), Floyd-Warshall (all-pairs), Kruskal/Prim MST.

Dijkstra · Bellman-Ford · MST · topological sort

Tries (Prefix Trees)

How autocomplete works. Insert, search, startsWith. Compressed tries (radix), how DNS resolvers use them, implementing a spell checker, and Aho-Corasick overview.

prefix tree · autocomplete · radix trie · search

Disjoint Sets (Union-Find)

Track connected components. Union by rank, path compression achieving near-O(1) amortized. Used in Kruskal's MST, network connectivity, image segmentation.

union-find · path compression · Kruskal

4 Expert — dynamic programming

Optimization via memoization and tabulation. Recognize the patterns, build the recurrence, and derive the solution systematically.

Dynamic Programming

Top-down (memoization) vs bottom-up (tabulation). Canonical patterns: Fibonacci, Knapsack (0/1 and unbounded), Longest Common Subsequence, Coin Change, Edit Distance, Longest Increasing Subsequence, Matrix Chain Multiplication.

memoization · tabulation · knapsack · LCS · edit distance
