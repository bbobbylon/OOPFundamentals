Real CPython, running in your browser — not a fake. This page loads Pyodide (the actual CPython interpreter compiled to WebAssembly), so print(), the standard library (math, json, dataclasses, collections…), real exceptions, and full tracebacks all behave exactly as they do on your machine. Press ▶ Run.

⚡ The interpreter is a one-time ~10 MB download the first time you run (it's then cached). It needs a network connection to fetch. After that, every run is instant and fully offline-capable.

🐍 What is this — and why does it matter?

Most "run Python in the browser" demos are a JavaScript re-implementation faking Python syntax. This one isn't — Pyodide compiles the real CPython interpreter (the same one on your machine) to WebAssembly and runs it directly in the tab. Every language feature, every standard-library module, every exception and traceback behaves exactly as it would on a server.

  • Write real Python — print(), list comprehensions, dataclasses, collections, real exceptions with real tracebacks.
  • Press ▶ Run and CPython actually parses, compiles to bytecode, and executes your code — no JS transpilation in between.
  • The engine toggle lets you compare running fully client-side (in-browser Pyodide) vs sending the same code to a real server API — same output, different execution location.
  • First run downloads the ~10 MB interpreter once; after that it's cached and every run is instant, even offline.

Why this is genuinely Python — and why that matters

It's the real interpreter

Pyodide is CPython itself, compiled to WebAssembly. The same bytecode, the same object model, the same SyntaxError and Traceback (most recent call last) you'd see in a terminal.

The stdlib is here

Pure-Python modules ship in the build — import json, dataclasses, itertools, collections, re, functools all work. (Packages with C extensions can be added with micropip.)

Indentation is syntax

Unlike curly-brace languages, Python uses whitespace to define blocks. Mix tabs and spaces and you get a real IndentationError — try it. Tab here inserts 4 spaces, the PEP 8 convention.
