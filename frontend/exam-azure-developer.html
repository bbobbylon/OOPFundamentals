Azure Developer Associate (AZ-204) — Practice Exam

Questions across ARM & resource groups, App Service, Functions, containers (ACR / ACI / Container Apps), Blob Storage, Cosmos DB, and Key Vault + Managed Identity — the AZ-204 core.

The mental model: everything in Azure is a resource inside a resource group, created through ARM, and secured by Entra ID + RBAC. AZ-204 rewards knowing WHICH service fits a scenario (App Service vs Functions vs Container Apps), how identity flows without secrets (Managed Identity → Entra → token → Key Vault / Blob / Cosmos), and the sharp edges: deployment-slot swaps, Functions cold starts, SAS scoping, Cosmos partition keys and 429 throttling. Practice mode links every answer to the visualizer that walks the exact flow. Drill until the bars are green on the dashboard.
