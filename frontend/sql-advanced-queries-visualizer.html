1 — Common Table Expressions (CTEs)




-- CTE: name a subquery for readability and reuse
WITH
  active_users AS (
    SELECT id, email FROM users WHERE active = true
  ),
  user_totals AS (
    SELECT au.id, COUNT(o.id) AS order_count, SUM(o.amount) AS total
    FROM active_users au
    LEFT JOIN orders o ON o.user_id = au.id
    GROUP BY au.id
  )
SELECT email, order_count, total
FROM active_users
JOIN user_totals USING (id)
WHERE order_count > 5
ORDER BY total DESC;


CTEs improve readability and allow reuse of the same subquery multiple times. In PostgreSQL 12+, the planner inlines CTEs by default — use MATERIALIZED to force a temp table if you want the old behavior.









2 — Window Functions




Window functions compute a result across rows related to the current row WITHOUT collapsing them (unlike GROUP BY). They use an OVER() clause.


SELECT
  email,
  amount,
  -- Ranking within each user
  ROW_NUMBER() OVER(PARTITION BY user_id ORDER BY amount DESC) AS rn,
  -- Running total per user
  SUM(amount) OVER(PARTITION BY user_id ORDER BY created_at) AS running_total,
  -- Previous row in the same partition
  LAG(amount) OVER(PARTITION BY user_id ORDER BY created_at) AS prev_amount
FROM orders;




FunctionWhat it computes


ROW_NUMBER()Unique sequential number — no ties


RANK()Rank with gaps for ties (1,1,3)


DENSE_RANK()Rank without gaps for ties (1,1,2)


LAG(col, n)Value from n rows before in partition


LEAD(col, n)Value from n rows after in partition


NTILE(n)Divide rows into n buckets (quartiles etc)











3 — Recursive CTE




Recursive CTEs traverse hierarchical data (org charts, file trees, category hierarchies) without knowing the depth in advance.


-- Org chart: find all reports under manager id=1
WITH RECURSIVE org_tree AS (
  -- Anchor: the root
  SELECT id, name, manager_id, 1 AS depth
  FROM employees WHERE id = 1

  UNION ALL

  -- Recursive part: join on previous result
  SELECT e.id, e.name, e.manager_id, ot.depth + 1
  FROM employees e
  JOIN org_tree ot ON e.manager_id = ot.id
)
SELECT REPEAT('  ', depth-1) || name AS name_indented, depth
FROM org_tree;









4 — CASE Expression




-- CASE for computed columns
SELECT
  order_id,
  amount,
  CASE
    WHEN amount < 50   THEN 'small'
    WHEN amount < 200  THEN 'medium'
    ELSE                    'large'
  END AS size_tier
FROM orders;

-- CASE for pivot (rows → columns)
SELECT
  user_id,
  SUM(CASE WHEN status = 'pending'   THEN 1 ELSE 0 END) AS pending_count,
  SUM(CASE WHEN status = 'completed' THEN 1 ELSE 0 END) AS completed_count
FROM orders
GROUP BY user_id;
