Stacks & Queues — Coding Practice

Six classic interview problems — LIFO/FIFO discipline, monotonic stacks, and two "design a data structure" problems. Real code, real hidden tests.

Two of these problems are "design" style — instead of writing one pure function, you'll write a function that replays a sequence of operations (like push, pop, getMin) and returns an array of their results, the same way an interviewer grades a whiteboard class design without needing a real class. The rest are classic single-function problems. Pick a language tab (JavaScript, TypeScript, or Python — all three run for real in your browser), write the function, press Run Tests. Stuck? Use a hint, or jump to the Stacks & Queues visualizer for the underlying technique.
