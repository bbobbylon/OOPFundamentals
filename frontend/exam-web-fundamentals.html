Web Fundamentals — Practice Exam

Questions across HTML semantics/forms/accessibility, CSS box model/specificity/selectors, Flexbox & Grid layout, JavaScript fundamentals (scoping, closures, this, hoisting), the DOM & events, async JavaScript, and how browsers actually render a page.

The mental model: the browser is a pipeline, and almost every "gotcha" in web fundamentals is about where in that pipeline something happens. HTML/CSS/JS gotchas cluster around a handful of repeat offenders — content-box vs border-box sizing, specificity beating source order, var's function scope vs let's block scope, this being call-site- not definition-site-determined, fetch() resolving on HTTP errors, and the microtask queue draining before any macrotask. Practice mode links every answer to the visualizer that walks the exact mechanism. Drill until the bars are green on the dashboard.
