Dynamic Programming — Coding Practice

Six classic interview problems — 1D DP recurrences and one 2D grid problem. Real code, real hidden tests, no partial credit for "the right idea."

DP is the topic where "I understand it conceptually" and "I can actually write it" diverge the most. Every problem here has a short, clean recurrence relation — the hard part is spotting it and translating it into a loop without an off-by-one bug. A hidden test suite is the fastest way to find out whether your recurrence is actually right, versus just right on the one example you traced by hand. Pick a language tab (JavaScript, TypeScript, Python, or Java — all four run for real in your browser), write the function, press Run Tests. Stuck? Use a hint, or jump to the Dynamic Programming visualizer for the underlying technique.
