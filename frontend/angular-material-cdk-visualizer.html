Angular Material & CDK — Component Library & Dev Kit

Google's Material Design components for Angular + the low-level CDK primitives that power them. Interactive demos for every component.

🧱 What is Angular Material — and what is the CDK that powers it?

Angular Material is a component library implementing Material Design — buttons, tables, dialogs, form fields, date pickers, 40+ more. Each component handles accessibility (ARIA, keyboard nav), theming, and Angular integration (reactive forms, DI, animations) so you don't redo it every project. The Component Dev Kit (CDK) is the layer beneath: a11y utilities, drag-and-drop, virtual scrolling, overlays, focus management. Use CDK primitives to build custom UI without Material's visual language, or to extend Material.

  • Material = ready-made, accessible, themeable components; CDK = the unstyled behaviour primitives under them.
  • The data-table trio (mat-table + mat-sort + mat-paginator) wires straight into server-side paging/sorting.
  • MatDialog, mat-form-field, mat-autocomplete integrate with Reactive Forms out of the box.
  • CDK's CdkVirtualScrollViewport, CdkDragDrop, Overlay, FocusTrap, A11yModule solve hard UI problems.
  • Theme once in styles.scss (a palette) and every Material component inherits it.

Most-used Material components

mat-table + mat-sort + mat-paginator (sortable, paged table); mat-dialog (accessible modal); mat-form-field + mat-input (Reactive-Forms fields); mat-snack-bar (toasts); mat-menu/mat-select/mat-autocomplete.

CDK — the useful parts

CdkVirtualScrollViewport (render only visible rows), CdkDragDrop + moveItemInArray(), Overlay (positioning for dialogs/menus/tooltips), FocusTrap (a11y for modals), A11yModule live announcer.

Theming

$theme: mat.define-theme({ color: { primary: mat.$azure-palette } }) then @include mat.all-component-themes($theme) — every component inherits the palette. Override per-component, and CSS custom properties (--mat-…) work in your styles.

In CIAM:user management = mat-table + server-side mat-paginator (page events call the API) + mat-sort; create/edit via MatDialog.open(UserFormComponent); delete via a ConfirmDialogComponent; a role picker with mat-autocomplete; and the audit log virtualized with CdkVirtualScrollViewport itemSize="48" (50 visible rows out of 50,000).

1. What Is Angular Material?

Angular Material

A UI component library built by the Angular team implementing Google's Material Design specification. Ready-made, accessible, theme-able components — buttons, inputs, tables, dialogs, and 50+ more.

CDK (Component Dev Kit)

The building blocks Angular Material is built on — virtual scrolling, drag-and-drop, overlay, portals, a11y utilities. Use CDK directly when you want the behavior without Material's visual style.

Key Benefit

ARIA roles, keyboard navigation, and focus management are handled for you. Accessibility out of the box. Theming is done with CSS custom properties and Sass mixins.

Installation

2. Theming System — Palettes, Typography & Dark Mode

Angular Material v17+ uses the new M3 (Material 3) theming API with mat.theme() and CSS custom properties. The old M2 mat-light-theme() / mat-dark-theme() still works but is deprecated.

M3 Theme Setup (styles.scss)

@use '@angular/material' as mat;

// Include core styles once (resets, overlays)
@include mat.core();

// Define a custom theme with your brand palette
$my-theme: mat.define-theme((
  color: (
    theme-type: light,       // or 'dark'
    primary: mat.$red-palette,
    tertiary: mat.$violet-palette,
  ),
  typography: (
    brand-family: 'Google Sans',
    plain-family: 'Roboto',
  ),
  density: (
    scale: 0,               // -4 (compact) to +4
  )
));

// Apply to root
:root {
  @include mat.all-component-themes($my-theme);
}

// Dark mode via selector
.dark-mode {
  $dark-theme: mat.define-theme((
    color: (theme-type: dark, primary: mat.$red-palette)
  ));
  @include mat.all-component-colors($dark-theme);
}

Typography Config

// Custom typography — applied globally
$my-typography: mat.define-typography-config((
  font-family: 'Inter, Roboto, sans-serif',
  headline-large: mat.define-typography-level(
    $size: 32px, $weight: 700
  ),
  body-medium: mat.define-typography-level(
    $size: 14px, $line-height: 20px
  ),
));

// M2 legacy typography (still widely used)
$m2-typography: mat.define-legacy-typography-config((
  $font-family: 'Inter, sans-serif',
  $display-4: mat.define-typography-level(112px, 1, 300)
));

// Apply typography in HTML:
// <body class="mat-typography">

6. MatDialog & MatSnackBar

Dialog Demo

MatDialog opens a component in an overlay panel. Data flows in via MAT_DIALOG_DATA and results flow back via afterClosed().

// Opening a dialog
const dialogRef = this.dialog.open(ConfirmDialog, {
  width: '400px',
  data: { title: 'Delete item?', id: 42 }
});

// Getting the result
dialogRef.afterClosed().subscribe(result => {
  if (result === 'confirm') this.deleteItem(42);
});

// Inside the dialog component
readonly data = inject<{title:string,id:number}>(MAT_DIALOG_DATA);
readonly dialogRef = inject(MatDialogRef);

confirm() { this.dialogRef.close('confirm'); }
cancel()  { this.dialogRef.close(); }

SnackBar Demo

MatSnackBar shows brief notifications at the bottom of the screen with an optional action button.

// Simple message

// With action callback

9. CDK — Component Dev Kit Overview

The CDK gives you behavior without styling. It's the layer between Angular's primitives and Angular Material's fully-styled components. Use it directly to build design-system-agnostic components.

@angular/cdk/scrolling

Virtual scrolling — render only visible rows for massive lists. Dramatically reduces DOM size and improves scroll performance.

CdkVirtualScrollViewport

@angular/cdk/drag-drop

Drag-and-drop lists, sortable grids, transferring items between lists. Handles touch, mouse, and keyboard.

cdkDrag, cdkDropList

@angular/cdk/overlay

Position floating panels (tooltips, dropdowns) relative to any element with advanced positioning strategies.

Overlay, OverlayRef

@angular/cdk/portal

Render a component or template outside its current location in the DOM tree — e.g., into a document-level container.

ComponentPortal, TemplatePortal

@angular/cdk/a11y

Accessibility utilities — trapping focus in dialogs, announcing to screen readers, monitoring focus source (mouse vs keyboard).

FocusTrap, LiveAnnouncer

@angular/cdk/table

An unstyled data table with the same data-binding API as MatTable. Build your own styled table using this foundation.

CdkTable, cdkColumnDef

10. CDK Virtual Scrolling — 10,000-Item List

The problem: Render 10,000 <div> elements into the DOM and you get a page that freezes. Virtual scrolling renders only the ~5–10 rows currently visible, replacing them as you scroll. The DOM stays small regardless of list size.

Live Virtual Scroll Demo

Rendering items 1–6 of 10,000 DOM nodes: 6

Scroll to see rendering window update in real time. Only the visible rows exist in the DOM.

<!-- CdkVirtualScrollViewport -->
<cdk-virtual-scroll-viewport
  itemSize="48"
  style="height: 400px">

  <div *cdkVirtualFor="let item of items"
       style="height: 48px">
    {{ item.name }}
  </div>

</cdk-virtual-scroll-viewport>

// Component
readonly items = Array.from(
  { length: 10_000 },
  (_, i) => ({ id: i + 1, name: `Item ${i + 1}` })

// With infinite scroll (load on demand)

// For variable-height items:

  autosize>   <!-- uses CdkAutoSizeVirtualScrollStrategy -->
</cdk-virtual-scroll-viewport>

11. CDK Drag & Drop

Drag to Reorder Demo

Drag the items below to reorder them. The cdkDropList handles the reorder logic automatically.

    <!-- Single list reorder -->
<ul cdkDropList
    [cdkDropListData]="items"
    (cdkDropListDropped)="drop($event)">

  <li *ngFor="let item of items"
      cdkDrag>
    <span cdkDragHandle>☰</span>
    {{ item.label }}
  </li>
</ul>

// Component handler
drop(event: CdkDragDrop<Item[]>) {
  moveItemInArray(
    this.items,
    event.previousIndex,
    event.currentIndex
  );
}

// Transfer between two lists
drop(event: CdkDragDrop<Item[]>) {
  if (event.previousContainer !== event.container) {
    transferArrayItem(
      event.previousContainer.data,
      event.container.data,
      event.previousIndex,
      event.currentIndex
    );
  } else {
    moveItemInArray(
      event.container.data,
      event.previousIndex,
      event.currentIndex
    );
  }
}

    12. CDK Overlay & Portal

    Custom Tooltip (Overlay)

    // Create a floating overlay programmatically
const overlay = inject(Overlay);
const viewContainerRef = inject(ViewContainerRef);

showTooltip(triggerEl: ElementRef) {
  const posStrategy = overlay.position()
    .flexibleConnectedTo(triggerEl)
    .withPositions([{
      originX: 'center', originY: 'top',
      overlayX: 'center', overlayY: 'bottom',
      offsetY: -8
    }]);

  const overlayRef = overlay.create({
    positionStrategy: posStrategy,
    scrollStrategy: overlay.scrollStrategies.reposition()
  });

  const portal = new ComponentPortal(TooltipComponent, viewContainerRef);
  overlayRef.attach(portal);
}
