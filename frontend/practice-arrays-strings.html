Arrays & Strings — Coding Practice

Six classic interview problems. Real code, real hidden tests, real pass/fail — no multiple choice.

This is the missing piece every other page here can't give you: actually writing code and having it graded. Quizzes and flashcards test whether you can recognize the right answer; visualizers show you how a technique works. This page hands you an empty function and a hidden test suite and makes you produce working code — the same bar a real interview or a real PR review holds you to. Pick a language tab (JavaScript, TypeScript, or Python — all three run for real in your browser, no server needed), write the function, press Run Tests. Stuck? Use a hint, or jump to the Arrays & Strings visualizer for the technique (two-pointer, sliding window, hashmap) each problem is built on.
