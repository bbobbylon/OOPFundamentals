DS Dynamic Programming

Memoization · tabulation · recognize the pattern · derive the recurrence · solve systematically

What Is Dynamic Programming?

DP is an algorithmic technique for problems with two properties: optimal substructure (optimal solution built from optimal sub-solutions) and overlapping subproblems (same sub-problems computed repeatedly). DP solves each subproblem once and stores the result.

Two Approaches

Top-Down (Memoization): Recursive solution + a cache (usually HashMap or array). On first call compute the answer; on subsequent calls return the cached value. Natural to write, recursive structure mirrors the recurrence.
Bottom-Up (Tabulation): Iterative. Fill a table starting from base cases, building up to the answer. No recursion stack; usually more memory-efficient; sometimes allows further space optimization.

How to Identify a DP Problem

  • Asks for maximum / minimum value
  • Asks to count the number of ways
  • Asks whether something is possible
  • Problem can be divided into smaller same-shape subproblems
  • Future choices don't depend on how you reached current state (no look-back)
  • Brute force is exponential but has repeated sub-computations

The 4-Step DP Framework

1. Define the state
dp[i] = "the answer to the subproblem of size i"
2. Write the recurrence
dp[i] = f(dp[i-1], dp[i-2], ...)
3. Identify base cases
dp[0] = 0, dp[1] = 1, etc.
4. Determine fill order
Each dp[i] must be computed after all its dependencies

Fibonacci — The Hello World of DP

Naive Recursion — O(2ⁿ)

int fib(int n) { if (n <= 1) return n; return fib(n-1) + fib(n-2); } // fib(50) computes fib(1) ~2.2B times! // Exponential — never use in practice

Memoization — O(n)

Map<Integer,Integer> memo = new HashMap<>(); int fib(int n) { if (n <= 1) return n; if (memo.containsKey(n)) return memo.get(n); int res = fib(n-1) + fib(n-2); memo.put(n, res); return res; } // Each n computed exactly once

Tabulation — O(n) time, O(1) space

int fib(int n) { if (n <= 1) return n; int prev2 = 0, prev1 = 1; for (int i = 2; i <= n; i++) { int curr = prev1 + prev2; prev2 = prev1; prev1 = curr; } return prev1; } // Sliding window: only 2 vars needed

Coin Change — Minimum Coins

Given coin denominations and a target amount, find the minimum number of coins to make the amount. Greedy doesn't always work (coins=[1,3,4], amount=6: greedy gives 4+1+1=3 coins, DP gives 3+3=2 coins).

// State: dp[a] = min coins to make amount a // Recurrence: dp[a] = 1 + min(dp[a - coin]) for each coin // Base case: dp[0] = 0 int coinChange(int[] coins, int amount) { int[] dp = new int[amount + 1]; Arrays.fill(dp, amount + 1); // "infinity" dp[0] = 0; for (int a = 1; a <= amount; a++) { for (int coin : coins) { if (coin <= a) { dp[a] = Math.min(dp[a], 1 + dp[a - coin]); } } } return dp[amount] > amount ? -1 : dp[amount]; }

Tracing coins=[1,3,4], amount=6

a0123456
dp[a] 0 1 2 1 1 2 2

dp[6]=2 → use coins {3,3}. Path: a=6 → a-3=3 → dp[3]=1 coin (coin "3") → dp[0]=0. Total 2 coins.

Coin Change II (count ways, not min coins): change outer loop to iterate coins first, inner loop amounts → prevents counting same combination multiple times. LeetCode 518.

0/1 Knapsack

Given items with weights and values, and a bag of capacity W: maximize total value without exceeding W. Each item is used at most once (0/1). Classic 2D DP.

State: dp[i][w] = max value using first i items with capacity w.
Recurrence: dp[i][w] = max(dp[i-1][w], dp[i-1][w-weight[i]] + value[i]) if weight[i] ≤ w
Base cases: dp[0][w] = 0 for all w (no items → zero value)
int knapsack(int[] weights, int[] values, int W) { int n = weights.length; int[][] dp = new int[n+1][W+1]; for (int i = 1; i <= n; i++) { for (int w = 0; w <= W; w++) { // Option 1: don't take item i dp[i][w] = dp[i-1][w]; // Option 2: take item i (if it fits) if (weights[i-1] <= w) { dp[i][w] = Math.max(dp[i][w], dp[i-1][w - weights[i-1]] + values[i-1]); } } } return dp[n][W]; } // Space optimization: 1D array (iterate w backwards!) int[] dp1d = new int[W+1]; for (int i = 0; i < n; i++) for (int w = W; w >= weights[i]; w--) // BACKWARDS! prevent reuse dp1d[w] = Math.max(dp1d[w], dp1d[w-weights[i]] + values[i]);

Example: 3 items, W=5

Unbounded Knapsack

Each item can be taken unlimited times. Change inner loop to forward (not backward) when using 1D array — allows reuse of same item multiple times. Example: Coin Change is unbounded knapsack.

Longest Common Subsequence (LCS)

Find the longest sequence present in both strings (not necessarily contiguous). Used in diff tools, bioinformatics (DNA alignment), git diff.

State: dp[i][j] = length of LCS of s1[0..i-1] and s2[0..j-1]
Recurrence: If s1[i-1]==s2[j-1]: dp[i][j] = 1 + dp[i-1][j-1]
              Else: dp[i][j] = max(dp[i-1][j], dp[i][j-1])
int lcs(String s1, String s2) { int m = s1.length(), n = s2.length(); int[][] dp = new int[m+1][n+1]; for (int i = 1; i <= m; i++) { for (int j = 1; j <= n; j++) { if (s1.charAt(i-1) == s2.charAt(j-1)) dp[i][j] = 1 + dp[i-1][j-1]; // chars match else dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]); // skip one } } return dp[m][n]; } // To reconstruct: backtrack from dp[m][n] // if s1[i-1]==s2[j-1]: include char, go to dp[i-1][j-1] // else: go to whichever of dp[i-1][j], dp[i][j-1] is larger

Edit Distance (Levenshtein)

Minimum number of single-character edits (insert, delete, replace) to transform s1 into s2. Used in: spell checkers, DNA comparison, fuzzy search.

int editDistance(String s1, String s2) { int m = s1.length(), n = s2.length(); int[][] dp = new int[m+1][n+1]; // Base cases: transform empty string for (int i = 0; i <= m; i++) dp[i][0] = i; // delete all from s1 for (int j = 0; j <= n; j++) dp[0][j] = j; // insert all of s2 for (int i = 1; i <= m; i++) { for (int j = 1; j <= n; j++) { if (s1.charAt(i-1) == s2.charAt(j-1)) { dp[i][j] = dp[i-1][j-1]; // no op needed } else { dp[i][j] = 1 + Math.min( dp[i-1][j], // delete from s1 Math.min( dp[i][j-1], // insert into s1 dp[i-1][j-1] // replace ) ); } } } return dp[m][n]; }

Longest Increasing Subsequence (LIS)

// O(n²) DP solution int lis(int[] nums) { int n = nums.length; int[] dp = new int[n]; Arrays.fill(dp, 1); // each element alone is LIS of length 1 for (int i = 1; i < n; i++) { for (int j = 0; j < i; j++) { if (nums[j] < nums[i]) { dp[i] = Math.max(dp[i], dp[j] + 1); } } } int max = 0; for (int v : dp) max = Math.max(max, v); return max; } // O(n log n) with patience sorting + binary search: int lisLogN(int[] nums) { List<Integer> tails = new ArrayList<>(); for (int x : nums) { int pos = Collections.binarySearch(tails, x); if (pos < 0) pos = -(pos + 1); if (pos == tails.size()) tails.add(x); else tails.set(pos, x); } return tails.size(); }

Example: [10, 9, 2, 5, 3, 7, 101, 18]

dp[i] = LIS length ending at index i
nums: [10, 9, 2, 5, 3, 7, 101, 18]
dp: [ 1, 1, 1, 2, 2, 3, 4, 4]

Answer: 4
LIS: 2, 3, 7, 101 (or 2, 3, 7, 18)
Related problems: Number of LIS (count all), Russian doll envelopes (2D LIS), box stacking — all reduce to LIS.

House Robber & Grid Paths

House Robber (Linear DP)

// Can't rob adjacent houses. Max loot. // dp[i] = max loot from first i houses // dp[i] = max(dp[i-1], dp[i-2] + nums[i]) int rob(int[] nums) { if (nums.length == 0) return 0; int prev2 = 0, prev1 = 0; for (int n : nums) { int curr = Math.max(prev1, prev2 + n); prev2 = prev1; prev1 = curr; } return prev1; } // Example: [2,7,9,3,1] // Rob 2,9,1 = 12. Or 7,3 = 10. Answer: 12.

Unique Paths (Grid DP)

// m×n grid, only right or down moves, count paths // dp[r][c] = paths to reach (r,c) = dp[r-1][c] + dp[r][c-1] int uniquePaths(int m, int n) { int[] dp = new int[n]; Arrays.fill(dp, 1); // first row: 1 way each for (int r = 1; r < m; r++) { for (int c = 1; c < n; c++) { dp[c] += dp[c-1]; // from left + from above } } return dp[n-1]; } // Math solution also exists: C(m+n-2, m-1)
