Hashmaps & Sets — Coding Practice

Six classic interview problems beyond Two Sum — frequency counting, prefix sums, and set membership. Real code, real hidden tests.

These go past the basic hashmap lookups from Arrays & Strings into the patterns that show up constantly once you're comfortable with the fundamentals: counting frequencies and breaking ties deterministically, turning "does a running total repeat" into O(n) subarray counting, and using a Set for O(1) membership checks instead of a nested loop. One note on Top K Frequent Elements: when two values tie in frequency, this page expects them ordered by value ascending — a real interview would usually accept any order for ties, but a fixed rule is what lets an automated test suite (here, or on any judge) grade it exactly.
