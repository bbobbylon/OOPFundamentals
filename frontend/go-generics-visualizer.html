1. Before Generics vs After

Before: copy-paste or interface{}

// Need a Map for int slice AND string slice
func MapInts(s []int, f func(int) int) []int {
  result := make([]int, len(s))
  for i, v := range s { result[i] = f(v) }
  return result
}
func MapStrings(s []string, f func(string) string) []string {
  // identical logic...
}

After: one generic Map

// One function, all types
func Map[T, U any](s []T, f func(T) U) []U {
  result := make([]U, len(s))
  for i, v := range s { result[i] = f(v) }
  return result
}

Map([]int{1,2,3}, func(x int) int { return x*2 })
Map([]string{"a","b"}, strings.ToUpper)

2. Constraints as Type Sets

// constraints.Ordered: all comparable + ordered types
type Ordered interface {
  ~int | ~int8 | ~int16 | ~int32 | ~int64 |
  ~float32 | ~float64 | ~string
}

func Min[T Ordered](a, b T) T {
  if a < b { return a }
  return b
}
// ~ means "underlying type"
type Celsius float64
type Fahrenheit float64

// ~float64 includes Celsius AND Fahrenheit
// because their underlying type is float64
Min(Celsius(37.0), Celsius(36.5)) // ✅ works
Min(37.0, Celsius(36.5)) // ✗ mixed types

The ~ prefix means "any type whose underlying type is X." Without ~, only the exact type matches. With ~, named types built on float64 also match.

Constraints are interfaces used as type sets. A constraint can list: allowed types (int | string), method requirements (Stringer), or both. any is interface{} — no constraint. comparable allows == and != (needed for map keys).

3. Generic Types (Data Structures)

// Generic Stack — works with any type
type Stack[T any] struct {
  items []T
}
func (s *Stack[T]) Push(v T) {
  s.items = append(s.items, v)
}
func (s *Stack[T]) Pop() (T, bool) {
  if len(s.items) == 0 {
    var zero T; return zero, false
  }
  n := len(s.items)-1
  v := s.items[n]; s.items = s.items[:n]
  return v, true
}
// Type must be specified for generic types (no inference)
s := &Stack[int]{} // int stack
s.Push(42)
s.Push(99)
v, ok := s.Pop() // v=99, ok=true

bs := &Stack[string]{} // string stack
bs.Push("hello")
// s.Push("hello") — COMPILE ERROR: string ≠ int

Generic types require explicit type argument at instantiation. Methods on generic types use [T] in the receiver: func (s *Stack[T]) Push(v T). The zero value trick (var zero T; return zero) returns the zero value of any type.
