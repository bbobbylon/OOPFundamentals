Arrays & Strings

Four core patterns that solve the majority of array and string interview problems.

What are the 4 core array/string patterns — and why does mastering them let you solve the vast majority of LeetCode medium problems?

Arrays and strings are the foundation of coding interviews — roughly 40% of interview problems at major tech companies are array/string problems. There are 4 patterns that, once internalized, cover the vast majority of them. Pattern 1 — Two Pointers: use two index variables (often left and right) that move toward each other or in the same direction. Eliminates the need for nested loops (reduces O(n²) to O(n)). Classic applications: Valid Palindrome (check from outside in), Two Sum II sorted array (move left if sum too small, right if too large), Container With Most Water (move the smaller pointer), Remove Duplicates from Sorted Array (slow/fast pointer). Key question: should the pointers face each other (converging) or move in the same direction (fast/slow)? Pattern 2 — Sliding Window: maintain a subarray or substring window defined by [left, right] boundaries. Expand right to grow the window, shrink left when a constraint is violated. Classic applications: Maximum Average Subarray (fixed window), Longest Substring Without Repeating Characters (variable window with HashMap), Minimum Size Subarray Sum (shrink when sum >= target), Permutation in String (fixed window with character frequency array). Pattern 3 — Prefix Sums: precompute cumulative sums so that range sum queries (sum from index i to j) become O(1) instead of O(n). prefix[j+1] - prefix[i] = sum of subarray i..j. Classic applications: Subarray Sum Equals K (prefix sum + HashMap to count), Range Sum Query (with precomputed array), Product of Array Except Self (prefix product + suffix product). HashMap variant: prefix sum → count allows detecting how many subarrays have exactly sum K. Pattern 4 — Sorting + Hash for Lookup: sort to enable binary search, two-pointer, or grouping; hash for O(1) membership. Classic applications: Group Anagrams (sort each string as key), 3Sum (sort + two pointers for inner loop), Meeting Rooms (sort by start time, check end >= next start), Top K Frequent Elements (bucket sort or MinHeap). When to use which: Two Pointers → problem mentions "pair with" or "from both ends" or "move inward"; Sliding Window → "subarray/substring with constraint on length or sum/characters"; Prefix Sum → "range sum query" or "count subarrays with sum"; Sorting+Hash → "group by," "pair exists," or "k most frequent."

Two Pointers — 3Sum

// 3Sum: find all triplets that sum to 0 // Without sorting: O(n³). With sort + two pointers: O(n²) List<List<Integer>> threeSum(int[] nums) { List<List<Integer>> res = new ArrayList<>(); Arrays.sort(nums); // sort first! Enables two-pointer + dedup for (int i=0; i<nums.length-2; i++) { if (i>0 && nums[i]==nums[i-1]) continue; // skip duplicate i int left=i+1, right=nums.length-1; while (left < right) { int sum = nums[i]+nums[left]+nums[right]; if (sum==0) { res.add(Arrays.asList(nums[i],nums[left],nums[right])); while (left<right&&nums[left]==nums[left+1]) left++; // dedup while (left<right&&nums[right]==nums[right-1]) right--; // dedup left++; right--; // move both inward } else if (sum<0) left++; // need bigger sum → move left right else right--; // need smaller sum → move right left } } return res; // O(n²) time, O(1) extra space }

Sliding Window — Longest No-Repeat

// Longest Substring Without Repeating Characters // Variable window: expand right, shrink left on violation // HashMap: char → most recent index int lengthOfLongestSubstring(String s) { Map<Character,Integer> map = new HashMap<>(); int maxLen=0, left=0; for (int right=0; right<s.length(); right++) { char c = s.charAt(right); // If char was in window, jump left past its last occurrence: if (map.containsKey(c) && map.get(c) >= left) { left = map.get(c) + 1; // shrink window from left } map.put(c, right); // update last-seen index maxLen = Math.max(maxLen, right - left + 1); // window size } return maxLen; // O(n) time, O(min(n,charset)) space } // Note: left NEVER decreases — the map.get(c)>=left check // prevents jumping left backward (stale map entry)

Prefix Sum — Subarray Sum = K

// Count subarrays with sum exactly equal to k // Key insight: sum(i..j) = prefixSum[j] - prefixSum[i-1] // So: sum(i..j)==k ↔ prefixSum[j] - prefixSum[i-1] == k // ↔ prefixSum[i-1] == prefixSum[j] - k // Count how many previous prefix sums equal (currentSum - k) int subarraySum(int[] nums, int k) { Map<Integer,Integer> prefixCount = new HashMap<>(); prefixCount.put(0, 1); // empty prefix has sum 0 (count=1) int sum=0, count=0; for (int num : nums) { sum += num; // running prefix sum // How many previous prefixes have sum (sum-k)? // Each one pairs with current prefix to form a subarray with sum k count += prefixCount.getOrDefault(sum-k, 0); prefixCount.merge(sum, 1, Integer::sum); // update map } return count; // O(n) time, O(n) space } // Works with negative numbers! Unlike sliding window approach // Works for k=0 (finds subarrays with no net sum change)

Interview / Context: Arrays/strings are the first thing interviewers test because they're unambiguous — there's nowhere to hide with a brute-force O(n²) solution when an O(n) two-pointer or sliding window exists. In your CIAM work, these exact patterns appear: Two Pointers → parsing and validating OAuth redirect URI lists; Sliding Window → rate limiting windows (count requests in last 60 seconds); Prefix Sum → cumulative audit log statistics. When you recognize the pattern in an interview, name it: "This looks like a sliding window problem because we need a contiguous subarray optimizing a constraint." Naming the pattern shows senior-level pattern recognition even before you write a line of code.
PATTERN 1

Two Pointers

Time: O(n) Space: O(1) Sorted array or pair/palindrome problems
When to use: sorted array pair sum, removing duplicates in-place, container with most water, valid palindrome. The key insight: two pointers avoid nested loops by using the sorted order or string symmetry to eliminate impossible pairs.

Template Code
int left = 0, right = arr.length - 1; while (left < right) { int sum = arr[left] + arr[right]; if (sum == target) { /* found! */ return new int[]{left, right}; } else if (sum < target) { left++; // need bigger sum → move left right } else { right--; // need smaller sum → move right left } }
Classic Problems
  • Two Sum II (sorted array) — find pair summing to target, O(n) time O(1) space
  • Valid Palindrome — skip non-alphanumeric, compare left & right inward
  • Container With Most Water — move the shorter line inward to maximize area
  • 3Sum — fix one element, two-pointer on the rest: O(n²) time
Two Sum II — Java Solution
public int[] twoSum(int[] numbers, int target) { int left = 0, right = numbers.length - 1; while (left < right) { int sum = numbers[left] + numbers[right]; if (sum == target) return new int[]{left + 1, right + 1}; // 1-indexed if (sum < target) left++; else right--; } return new int[]{-1, -1}; // not found }
PATTERN 2

Sliding Window

Time: O(n) Space: O(1) to O(k) Contiguous subarray/substring with constraint
When to use: any problem asking for max/min/longest/shortest subarray or substring satisfying some constraint (max sum, at most k distinct chars, no repeating chars). The window expands right, then shrinks from left when the constraint is violated.

Variable Window Template
int left = 0, maxLen = 0; Map<Character, Integer> window = new HashMap<>(); for (int right = 0; right < s.length(); right++) { char c = s.charAt(right); window.put(c, window.getOrDefault(c, 0) + 1); // expand right while (window.get(c) > 1) { // shrink left until valid char leftChar = s.charAt(left); window.put(leftChar, window.get(leftChar) - 1); if (window.get(leftChar) == 0) window.remove(leftChar); left++; } maxLen = Math.max(maxLen, right - left + 1); } return maxLen;
Classic Problems
  • Longest Substring Without Repeating Characters — track last seen index in HashMap
  • Maximum Average Subarray I — fixed window of size k, slide by one each step
  • Minimum Window Substring — variable window, count chars needed vs chars have
  • Permutation in String — fixed window = len(p), check frequency maps match
PATTERN 3

Prefix Sum

Build: O(n)   Query: O(1) Space: O(n) Range sum queries or subarray sum = k
When to use: multiple range sum queries, or finding subarrays that sum to exactly k. Key formula: sum(i..j) = prefix[j+1] - prefix[i]. For subarray sum = k, use a HashMap of prefix sums seen so far.

Subarray Sum Equals K — O(n) with HashMap
public int subarraySum(int[] nums, int k) { Map<Integer, Integer> prefixCount = new HashMap<>(); prefixCount.put(0, 1); // empty prefix int count = 0, runningSum = 0; for (int num : nums) { runningSum += num; // if (runningSum - k) was seen before, subarrays summing to k exist count += prefixCount.getOrDefault(runningSum - k, 0); prefixCount.merge(runningSum, 1, Integer::sum); } return count; }
PATTERN 4

Hash Map Counting

Time: O(n) Space: O(n) Frequency counting, Two Sum (unsorted), anagram detection
When to use: whenever you need to remember previously seen values or count occurrences. HashMap trades space for time — O(1) lookup replaces O(n) scan. Pattern: for each element, check if complement/match is in map, then add current to map.

Two Sum — O(n) with HashMap
public int[] twoSum(int[] nums, int target) { Map<Integer, Integer> seen = new HashMap<>(); // value → index for (int i = 0; i < nums.length; i++) { int complement = target - nums[i]; if (seen.containsKey(complement)) return new int[]{seen.get(complement), i}; seen.put(nums[i], i); } return new int[]{-1, -1}; }
Valid Anagram — O(n) with frequency array
public boolean isAnagram(String s, String t) { if (s.length() != t.length()) return false; int[] freq = new int[26]; for (char c : s.toCharArray()) freq[c - 'a']++; for (char c : t.toCharArray()) { freq[c - 'a']--; if (freq[c - 'a'] < 0) return false; } return true; }
Classic Problems
  • Two Sum — store value→index, check complement each step
  • Valid Anagram — frequency array of size 26 or HashMap
  • Group Anagrams — map sorted-string → list of originals
  • Top K Frequent Elements — frequency map + bucket sort or min-heap

Java String / Array API Cheat Sheet

  • s.toCharArray() — convert String to char[], enables index access and modification
  • s.charAt(i) — get char at index (prefer over toCharArray for read-only)
  • Character.isLetterOrDigit(c), Character.toLowerCase(c) — use for palindrome checks
  • new StringBuilder(s).reverse().toString() — reverse a string
  • String.valueOf(charArr) — char[] back to String
  • s.equals(t) NOT s == t — always use .equals() for String comparison
  • Arrays.sort(arr) — sorts primitives in-place, O(n log n) dual-pivot quicksort
  • int[] freq = new int[26]; freq[c - 'a']++ — O(1) space frequency for lowercase letters
