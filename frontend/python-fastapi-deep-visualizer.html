FastAPI Deep Dive

FastAPI routes, Pydantic validation, dependency injection, OAuth2 Bearer auth, background tasks, and how it maps to Spring Boot concepts you already know.

🚀 What is FastAPI — and how does it compare to Spring Boot?

FastAPI is Python's closest equivalent to Spring Boot — a modern async REST framework on Starlette + Pydantic that auto-generates OpenAPI docs. Routes are decorated async functions; path/query/body/header params are declared as function parameters and validated automatically. Request bodies are typed Pydantic models (a 422 with field errors on failure = @Valid + Bean Validation). It has built-in DI via Depends(...) (inject a DB session or the current user from a JWT), background tasks (≈ @Async), and Swagger at /docs with zero config.

  • Python's Spring Boot — async routes, validation, DI, OpenAPI out of the box.
  • Pydantic validates request bodies — typed models, automatic 422s (≈ @Valid).
  • Depends(...) is the DI system — inject DB sessions, the current user from a JWT.
  • /docs Swagger is free — built from your models and routes.

FastAPI vs Spring Boot

FastAPI concept → Spring Boot equivalent. @app.get('/path') → @GetMapping("/path"). body: CreateUserReq parameter → @RequestBody @Valid CreateUserRequest body. Depends(get_db) → @Autowired UserRepository repo. Depends(get_current_user) → Spring Security's @AuthenticationPrincipal UserDetails user. Pydantic BaseModel → Java record DTO with Bean Validation annotations. HTTPException(status=401) → Spring's ResponseEntity<>(HttpStatus.UNAUTHORIZED). BackgroundTasks → @Async void sendEmail(). response_model= → Spring's DTO return type (Jackson serializes). FastAPI auto-docs at /docs → Spring's springdoc-openapi at /swagger-ui.html. Both frameworks follow the same pattern: validate input → process → return structured response.

CIAM use cases: A provisioning endpoint queues background syncs — bg.add_task(sync_to_ping, req); bg.add_task(sync_to_entra, req); return {"status":"queued"} — returning immediately (≈ @Async). A signed Ping webhook receiver verifies the signature then processes the event, and @app.get('/actuator/health') mirrors Actuator. The async model serves hundreds of concurrent webhook deliveries on one process without pool exhaustion.

1. FastAPI vs Spring Boot — the Same Idea

🌿 Spring Boot (Java)
@RestController
@RequestMapping("/users")
public class UserController {
  @Autowired
  private UserService svc;

  @PostMapping
  @ResponseStatus(CREATED)
  public UserDto create(
    @Valid @RequestBody CreateUserReq req) {
    return svc.create(req);
  }
}
🐍 FastAPI (Python)
from fastapi import FastAPI, Depends
from pydantic import BaseModel

app = FastAPI()

class CreateUser(BaseModel):
    name: str
    email: str

@app.post("/users", status_code=201)
async def create_user(
    body: CreateUser,
    db: Session = Depends(get_db)
):
    return svc.create(body, db)

Both frameworks: route → inject dependencies → validate input → call service → return response. FastAPI uses Python type hints where Spring uses annotations.

2. Pydantic Models = Spring's @Valid + DTO in One

from pydantic import BaseModel, EmailStr, Field
from typing import Optional

class CreateUser(BaseModel):
    name: str = Field(min_length=2, max_length=50)
    email: EmailStr
    age: Optional[int] = None

# Pydantic VALIDATES and COERCES on construction:
user = CreateUser(name="Alice", email="alice@example.com", age="30")
# age="30" (string) → coerced to int 30
user.age  # 30 (int), not "30" (str)

3. Dependency Injection — Depends()

from fastapi import Depends, HTTPException, status
from fastapi.security import OAuth2PasswordBearer

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")

async def get_current_user(token: str = Depends(oauth2_scheme)):
    user = verify_jwt(token)
    if not user:
        raise HTTPException(status_code=401)
    return user

async def require_admin(user = Depends(get_current_user)):
    if "admin" not in user.roles:
        raise HTTPException(status_code=403)
    return user
