1. FastAPI vs Spring Boot — the Same Idea

🌿 Spring Boot (Java)
@RestController
@RequestMapping("/users")
public class UserController {
  @Autowired
  private UserService svc;

  @PostMapping
  @ResponseStatus(CREATED)
  public UserDto create(
    @Valid @RequestBody CreateUserReq req) {
    return svc.create(req);
  }
}
🐍 FastAPI (Python)
from fastapi import FastAPI, Depends
from pydantic import BaseModel

app = FastAPI()

class CreateUser(BaseModel):
    name: str
    email: str

@app.post("/users", status_code=201)
async def create_user(
    body: CreateUser,
    db: Session = Depends(get_db)
):
    return svc.create(body, db)

Both frameworks: route → inject dependencies → validate input → call service → return response. FastAPI uses Python type hints where Spring uses annotations.

2. Pydantic Models = Spring's @Valid + DTO in One

from pydantic import BaseModel, EmailStr, Field
from typing import Optional

class CreateUser(BaseModel):
    name: str = Field(min_length=2, max_length=50)
    email: EmailStr
    age: Optional[int] = None

# Pydantic VALIDATES and COERCES on construction:
user = CreateUser(name="Alice", email="alice@example.com", age="30")
# age="30" (string) → coerced to int 30
user.age  # 30 (int), not "30" (str)
# FastAPI auto-generates OpenAPI from your models:
@app.post("/users", response_model=UserResponse)
async def create_user(body: CreateUser):
    # body is already validated CreateUser instance
    return UserResponse(...)

# Invalid input → automatic 422 Unprocessable Entity:
# POST /users {"name": ""} → 422
# {"detail": [{"loc": ["body","name"],"msg": "String should have at least 2 characters"}]}

3. Dependency Injection — Depends()

from fastapi import Depends, HTTPException, status
from fastapi.security import OAuth2PasswordBearer

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")

async def get_current_user(token: str = Depends(oauth2_scheme)):
    user = verify_jwt(token)
    if not user:
        raise HTTPException(status_code=401)
    return user

async def require_admin(user = Depends(get_current_user)):
    if "admin" not in user.roles:
        raise HTTPException(status_code=403)
    return user
