Number of Islands — DFS Template
public int numIslands(char[][] grid) { int count = 0; for (int i = 0; i < grid.length; i++) for (int j = 0; j < grid[0].length; j++) if (grid[i][j] == '1') { dfs(grid, i, j); count++; } return count; } private void dfs(char[][] grid, int r, int c) { if (r < 0 || r >= grid.length || c < 0 || c >= grid[0].length || grid[r][c] != '1') return; grid[r][c] = '0'; // mark visited in-place dfs(grid, r+1, c); dfs(grid, r-1, c); dfs(grid, r, c+1); dfs(grid, r, c-1); }
General Graph DFS Template
void dfs(int node, boolean[] visited, List<Integer>[] adj) { visited[node] = true; for (int neighbor : adj[node]) if (!visited[neighbor]) dfs(neighbor, visited, adj); } // Count connected components: int components = 0; for (int i = 0; i < n; i++) if (!visited[i]) { dfs(i, visited, adj); components++; }
Classic Problems
  • Number of Islands — DFS flood-fill from each unvisited '1'
  • Max Area of Island — DFS returns area count from each island start
  • Clone Graph — DFS with HashMap old→new to avoid revisiting

BFS Template
int bfsShortestPath(int[][] grid, int[] start, int[] end) { int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}}; Queue<int[]> q = new LinkedList<>(); q.add(new int[]{start[0], start[1], 0}); // {row, col, dist} boolean[][] visited = new boolean[grid.length][grid[0].length]; visited[start[0]][start[1]] = true; while (!q.isEmpty()) { int[] curr = q.poll(); if (curr[0] == end[0] && curr[1] == end[1]) return curr[2]; for (int[] d : dirs) { int r = curr[0] + d[0], c = curr[1] + d[1]; if (r>=0 && r<grid.length && c>=0 && c<grid[0].length && !visited[r][c] && grid[r][c]==0) { visited[r][c] = true; q.add(new int[]{r, c, curr[2] + 1}); } } } return -1; // not reachable }

Topological Sort (DAG)

Time: O(V + E) Space: O(V) Task ordering, course prerequisites, build systems
Kahn's Algorithm (BFS-based): compute in-degrees of all nodes, start with 0-in-degree nodes, process and reduce neighbors' in-degrees. If all nodes are processed, no cycle. If count < n, cycle exists.

Kahn's Algorithm — Java
public int[] findOrder(int numCourses, int[][] prerequisites) { List<Integer>[] adj = new ArrayList[numCourses]; int[] inDegree = new int[numCourses]; for (int i = 0; i < numCourses; i++) adj[i] = new ArrayList<>(); for (int[] pre : prerequisites) { adj[pre[1]].add(pre[0]); inDegree[pre[0]]++; } Queue<Integer> q = new LinkedList<>(); for (int i = 0; i < numCourses; i++) if (inDegree[i] == 0) q.add(i); int[] order = new int[numCourses]; int idx = 0; while (!q.isEmpty()) { int node = q.poll(); order[idx++] = node; for (int neighbor : adj[node]) if (--inDegree[neighbor] == 0) q.add(neighbor); } return idx == numCourses ? order : new int[0]; // empty if cycle }
Classic Problems
  • Course Schedule — detect cycle: topological sort count < numCourses means cycle
  • Course Schedule II — return the topological order itself
  • Alien Dictionary — build ordering constraints from word comparisons, then topo sort
PATTERN 4

Dijkstra — Weighted Shortest Path

Time: O((V+E) log V) Space: O(V) Weighted graph, non-negative edges only
Key idea: min-heap (PriorityQueue) processes nodes in order of their current shortest distance. When a node is popped, its distance is finalized (greedy property holds for non-negative edges). Note: Dijkstra fails with negative edges — use Bellman-Ford instead.
Dijkstra — Java
public int[] dijkstra(int n, List<int[]>[] adj, int src) { int[] dist = new int[n]; Arrays.fill(dist, Integer.MAX_VALUE); dist[src] = 0; PriorityQueue<int[]> pq = new PriorityQueue<>((a,b) -> a[0] - b[0]); // [dist, node] pq.offer(new int[]{0, src}); while (!pq.isEmpty()) { int[] curr = pq.poll(); int d = curr[0], u = curr[1]; if (d > dist[u]) continue; // stale entry for (int[] edge : adj[u]) { // [neighbor, weight] int v = edge[0], w = edge[1]; if (dist[u] + w < dist[v]) { dist[v] = dist[u] + w; pq.offer(new int[]{dist[v], v}); } } } return dist; }
Classic Problems
  • Network Delay Time — Dijkstra from source, return max dist (or -1 if unreachable)
  • Cheapest Flights Within K Stops — Bellman-Ford (k+1 relaxations) or modified Dijkstra
  • Path With Minimum Effort — Dijkstra where "distance" = max edge weight on path
PATTERN 5

Grid Graphs

A 2D grid is an implicit graph: each cell is a node, adjacent cells are edges. The 4-directional movement array int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}} is your adjacency list. BFS for minimum steps, DFS for flood-fill/regions.
Grid DFS / BFS Template
int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}}; // Bounds check helper boolean inBounds(int r, int c, int rows, int cols) { return r >= 0 && r < rows && c >= 0 && c < cols; } // Multi-source BFS (Rotting Oranges): start with all sources in queue for (int r = 0; r < rows; r++) for (int c = 0; c < cols; c++) if (grid[r][c] == 2) q.add(new int[]{r, c});
Classic Grid Problems
  • Rotting Oranges — multi-source BFS from all rotten oranges simultaneously
  • Pacific Atlantic Water Flow — BFS/DFS from all Pacific border cells + all Atlantic border cells; return intersection
  • Surrounded Regions — DFS from all border 'O' cells to mark safe, flip remaining 'O' to 'X'
  • Walls and Gates — multi-source BFS from all gates (0-cells) to fill distances

Java Graph Tips

  • Deque<int[]> q = new ArrayDeque<>() — BFS with coordinates; add {row, col, dist}
  • int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}} — 4-directional; add {-1,-1},{1,1},{-1,1},{1,-1} for 8-directional
  • Modify grid in-place to mark visited (set to 0 or '#') to avoid separate visited array
  • Multi-source BFS: add all sources to queue before starting — they all start at distance 0
  • PriorityQueue for Dijkstra: (a,b) -> Integer.compare(a[0], b[0]) (safe; avoids int overflow)
